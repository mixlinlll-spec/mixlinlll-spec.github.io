:::safety 開始前
只接 USB，不用接電池，拆下螺旋槳。更新過程中不要拔線、不要讓電腦進入睡眠。
:::

## 要不要更新？

飛機現在飛得好好的，沒有一定要更新。需要新功能、修正某個已知問題，或新零件要求新版本時再更新。Betaflight 從 2025.12 起改用「年份.月份」命名（例如 2025.12、2026.6），大約每半年一版，電腦軟體也改成網頁版 Betaflight App。

## 更新前的準備

1. **記下目前版本與飛控型號**：在命令列輸入 `status` 可以看到版本與硬體資訊；飛控型號以板子背面的完整名稱為準，不要只看處理器名稱。
2. **備份設定**：在「預設設定（Presets）」頁按儲存備份，或在命令列輸入 `diff all` 後存成檔案。另外截圖「連接埠」頁，記住每個 UART 接了什麼。
3. **確認新版支援你的飛控**：在韌體更新頁按自動偵測，畫面上的板子名稱要和你的飛控一樣。
4. **準備好接線**：用一條確定能傳資料的 USB 線，直接插電腦。

## 依狀況處理

:::case A 更新後設定全部不見
這是正常的：Betaflight 官方說明，刷韌體一定會清掉原本的設定。

1. **同一個版本才直接載回備份**：備份檔裡的版本和現在一樣，才用「預設設定」頁載入備份或在命令列載入。
2. **版本不同就照畫面重新設定**：新版本可能增加、刪除或改了設定名稱，整份貼上舊設定可能出錯。依序重新設定接收機、解鎖開關、馬達、OSD 畫面資訊與電壓。
3. **設定完拆槳做完整地面測試**：接收機通道、解鎖、馬達順序與轉向都正常後，才裝槳試飛。
:::

:::case B 更新中斷，飛控無法開機
1. **不要反覆插拔或重刷**：先停下來，照下面的方式恢復。
2. **進入刷機模式**：按住飛控上的 BOOT 按鍵再插 USB，電腦出現 STM32 BOOTLOADER 代表還能恢復。
3. **重新刷入原本型號的韌體**：在韌體更新頁選擇和飛控完全相同的型號再刷。不確定型號就停止，請看文末「還是不行？」。
4. **不是飛控的裝置**：ELRS 接收機能進 Wi-Fi 更新頁時，用原本型號的韌體檔恢復；DJI 裝置接回官方 DJI Assistant 2，照畫面重新更新。
:::

:::case C 刷完後找不到陀螺儀
1. **核對型號**：對照板子背面的完整型號，和刷入的型號是不是同一個。同一顆處理器可能有好幾種不同的板子。
2. **刷回該型號官方支援的版本**：重新刷入正確型號，再看「設定」頁是否偵測到陀螺儀。
3. **兩個相容版本都找不到陀螺儀**：停止反覆刷機，可能是硬體問題，請看文末「還是不行？」。
:::

:::advanced 進階：Full Chip Erase 與刷機模式
韌體更新頁的 Full Chip Erase（完整清除晶片）預設是開啟的，會把設定區清成新版本的預設值。官方建議只有在確定設定的資料結構沒有變過時才關閉，不確定就保持開啟。

進入刷機模式也可以在「設定」頁按 Activate Boot Loader / DFU，或在命令列輸入 `bl`。接收機、GPS 等周邊有時會干擾進入刷機模式。
:::

:::checks 怎樣算修好
- 「設定」頁顯示的版本是你剛刷入的版本，陀螺儀與加速度計都有偵測到（3D 飛機會跟著手轉）
- 「接收機」頁撥搖桿，每支都動到正確的通道
- 拆槳在「馬達」頁測試，順序與轉向都和畫面圖一致
:::

:::stop 什麼時候停手
不確定飛控型號、同一塊板子刷了兩次以上還是異常，或飛控接 USB 就發燙：停止操作，不要再試別的型號韌體。
:::
