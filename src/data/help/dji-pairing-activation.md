## 常見原因
- 新的天空端還沒啟用
- 天空端和眼鏡韌體版本不同
- USB 線只能充電、不能傳資料

## 檢查步驟
1. **先啟用**：用 DJI Fly App 或 DJI Assistant 2 啟用新的天空端與眼鏡。
2. **配對**：天空端接電池、眼鏡開機，照 DJI 說明書同時按兩邊的配對鍵，等燈號變綠。
3. **韌體版本**：配對不上時，用 DJI Assistant 2 把天空端和眼鏡都更新到最新版。
4. **電腦找不到裝置**：換一條能傳資料的 USB 線、換一個 USB 孔；天空端同時接上電池供電再試。

:::checks 怎樣算修好
- 天空端綠燈，眼鏡有畫面
- DJI Assistant 2 看得到裝置
:::

:::stop 什麼時候停手
更新韌體中斷、裝置開不了機：不要反覆重插，請聯絡 EWP。
:::
