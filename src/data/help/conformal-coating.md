:::safety 開始前
塗之前拔掉電池並斷開 USB。依塗層產品標示，在通風處作業，等完全乾燥後再通電。
:::

## 先決定要不要上

| 你的使用情境 | 建議 |
| --- | --- |
| 常在潮濕、草地、雪地或海邊飛 | 建議上 |
| 只在乾燥環境飛、常需要改線維修 | 可以不上，維修比較方便 |
| 想讓飛機可以泡水 | 防水漆做不到，它只能擋潮氣與噴濺 |

## 建議作法

1. **先組好、測試正常再塗**：塗了之後改線會比較麻煩。
2. **避開這些位置**：USB 座、BOOT 按鍵、接頭、氣壓計、相機感光元件、圖傳和接收機的按鍵。接頭可以先插上再塗。
3. **薄塗**：用刷的，一到兩層就好，每層依產品說明等乾。
4. **維修前要先清掉**：塗層會讓焊接變困難，維修前要依塗層產品的說明移除。

:::checks 怎樣算塗好
- 塗層完全乾燥後，USB 能正常連線、BOOT 按鍵按得下去
- 上電後所有功能正常（陀螺儀、接收機、圖傳）
- 接頭、按鍵、氣壓計與相機感光元件沒有沾到塗層
:::

:::stop 什麼時候停手
塗層還沒乾就通電、塗到 USB 座或接頭導致接觸不良、上電後有零件異常發熱：立刻斷電，等完全乾燥或清除塗層後再檢查。
:::
