:::safety 開始前
拔掉電池、拆下螺旋槳再檢查。剛飛完的馬達可能很燙，先放涼再用手碰。
:::

## 依狀況處理

:::case A 只有一顆馬達特別燙，或已經燒黑
1. **用手轉那顆馬達**：斷電後慢慢轉，正常是順暢、阻力平均；卡卡的、有段落感或聽到摩擦聲，代表軸承或內部有問題。
2. **看外殼和軸**：馬達外殼（鐘罩）有沒有被撞凹、轉動時有沒有偏擺，底部有沒有頭髮、草屑纏住。
3. **看那片槳和那支機臂**：槳有沒有缺角、裂痕或裝反；機臂有沒有裂開或螺絲鬆動。機臂鬆動會讓那顆馬達一直出力修正而發熱。
4. **漆包線有燒黑或焦味**：那顆馬達不要再用，同時那一路電調也可能受損，請看文末「還是不行？」。
:::

:::case B 剛換過馬達螺絲，一顆馬達馬上發熱
螺絲太長會頂到馬達內部的線圈（漆包線），造成短路發熱。這比調參更該先查。

1. **拆下那顆馬達看螺絲**：螺絲鎖進去的長度不能超過馬達底座可用的深度。
2. **看線圈**：漆包線有刮傷、被壓扁或燒黑，那顆馬達停用。
3. **換對長度的螺絲**：依機臂厚度選長度，不是只看螺絲規格；手邊沒有短螺絲時，可以加墊片調整。
:::

:::case C 怠速時抖動，或起飛時突然卡一下
1. **換一組完好的槳**：缺角、裂痕或變形的槳會讓馬達抖動，抖動與果凍的檢查也可以看 [[vibration-jello]]。
2. **看馬達螺絲和馬達線**：固定螺絲有沒有鬆、三條馬達線有沒有鬆脫或焊點裂開。
3. **換一顆狀態好的電池短測**：電池老化或電壓不足也會讓起飛瞬間沒力、卡頓，詳見 [[battery-flight-time]]。
4. **還是會卡**：先停止飛行，不要自己更改電調的進階選項。
:::

:::case D 轉起來有沙沙聲
1. **斷電用手慢轉**：聽有沒有沙沙聲或一格一格的感覺。
2. **清掉纏在底部的異物**：頭髮、草屑清乾淨後再轉一次。
3. **上下拉一拉外殼**：可以明顯上下晃動，代表軸承鬆了。
4. **摔機後軸彎了**：軸彎曲的馬達要更換，彎軸會一直產生震動；軸承磨損可以只換軸承，或直接換馬達。
:::

:::advanced 進階：用三用電錶檢查螺絲是否碰到線圈
先拔掉電池、拆槳，把那顆馬達從機臂拆下，再把原本的螺絲鎖回馬達底座（不要鎖在機臂上：碳纖機臂會導電，可能讓結果誤判）。三用電錶切到導通（會「嗶」的那一檔），一支表筆碰螺絲，另一支依序碰三條馬達線（馬達線還焊在電調上時，碰電調上的馬達焊點）。任一條發出嗶聲或電阻接近零，代表那顆螺絲碰到線圈，每一顆螺絲都要測。不熟悉電表操作，交給 EWP 檢測。
:::

:::checks 怎樣算修好
- 斷電用手轉每顆馬達：都一樣順，沒有卡頓、沙沙聲或上下晃動
- 拆槳在「馬達」頁低速測試：每顆聲音一致
- 裝槳短時間低空懸停後降落、拔掉電池，用紅外線測溫槍量四顆馬達外殼：溫度差不多，沒有哪一顆特別燙。沒有測溫槍時，手背先靠近感覺熱氣、再短暫輕碰外殼比較，不要握住；剛飛完的馬達可能很燙
:::

:::stop 什麼時候停手
馬達或電調冒煙、有燒焦味、漆包線燒黑，或四顆馬達都燙到不敢摸：可以安全操作時拔掉電池，不要再飛；電池本身發熱或冒煙時不要用手拿，人先遠離。四顆都燙通常不是單一零件問題，請把設定與飛行狀況交給 EWP 判斷。
:::
