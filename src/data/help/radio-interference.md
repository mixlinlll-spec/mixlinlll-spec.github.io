:::safety 開始前
干擾還沒排除前，不要飛遠，也不要在其他人上方飛行。先照 [[failsafe-check]] 確認斷控時飛機會照設定停機或返航。
:::

## 看結果判斷

| 看到的情況 | 代表什麼 | 下一步 |
| --- | --- | --- |
| 自己一台飛，2.4G 遙控＋2.4G 圖傳，距離很短 | 可能是同一台飛機上的兩套 2.4G 互相干擾（也可能是天線或供電問題） | A |
| 只有好幾台一起飛時才斷訊或畫面互串 | 比較可能是頻道互相干擾 | B |
| 降低圖傳功率後明顯改善 | 可能是圖傳太強壓過接收機 | A 第 2 步 |
| 自己一台飛也一樣斷 | 不一定是干擾 | 看 [[range-dropouts]] |

## 依狀況處理

:::case A 同一台飛機上的 2.4G 遙控與 2.4G 圖傳
1. **天線拉開**：兩套天線盡量拉開距離，不要並排或交叉壓在一起。
2. **降低圖傳功率測試**：先用低功率近距離飛，情況明顯改善，比較可能是互相干擾。
3. **不要只刷韌體換頻段**：不同頻段需要對應的硬體與天線，也要符合當地規定，不能只靠刷韌體把 2.4G 改成 900M。
:::

:::case B 多台同場一起飛
1. **類比圖傳先分配頻道**：同場每台用不同頻道，頻道之間拉開，不要用相鄰頻道。
2. **數位圖傳各用不同頻道**：避免全部設成自動。可選的頻道數依頻寬而定，頻寬越寬可選的越少（例如 DJI O4 看 [[dji-signal-quality]]），同場台數多時要一起改窄頻寬。
3. **一台一台加入**：先只開一台的圖傳，再逐台打開，找出是哪兩台衝突。
4. **降低不必要的功率**：近距離飛行不需要開到最大功率。綁定密語只用來區分是哪一台遙控器，不會消除無線干擾。
:::

:::checks 怎樣算修好
- 同一台飛機上兩套 2.4G 系統一起開，近距離飛行時畫面與遙控都不會斷
- 多台同場時，各台畫面互不干擾、不會看到別人的畫面
- 一台一台加入時，每加入一台都沒有出現新的斷訊
:::

:::stop 什麼時候停手
飛行中出現 RXLOSS 或畫面頻繁中斷：立刻往回飛並降落。多台同場時，有人的飛機失控，所有人先降落。
:::
