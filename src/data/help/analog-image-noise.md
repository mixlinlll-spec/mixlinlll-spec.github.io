:::safety 開始前
拆下螺旋槳。不要手持裝了槳的飛機推大油門測試橫紋；需要帶負載重現時，用合適的測試架與設備。
:::

## 依狀況處理

:::case A 橫紋跟著油門變多
電調和馬達會讓電源產生高頻雜訊，鏡頭和圖傳如果直接吃電池電，雜訊就會變成畫面上跳動的橫紋。這種雜訊一般三用電表量不出來。

1. **看供電來源**：鏡頭、圖傳是直接接電池電壓，還是接飛控的穩壓輸出？
2. **看接地與焊點**：電池主線、鏡頭與圖傳的地線焊點有沒有虛焊；所有設備要共地。
3. **影像線遠離大電流線**：鏡頭影像線不要和馬達線、電調電源線綁在一起。
4. **換穩定的供電比較**：斷電後改用乾淨的穩壓供電（例如圖傳的 5V 輸出、或飛控的穩壓焊點）給鏡頭。先確認那個輸出的電壓在鏡頭規格的輸入範圍內（原本接 5V 的鏡頭改接 9V、10V 焊點可能燒毀），電流也夠用。EWP 實際案例中，改由圖傳 5V 輸出供電給鏡頭、影像經飛控 OSD 再進圖傳、全部共地後，橫紋消失；但不是每台都適用。
5. **加濾波**：LC 濾波器要選電流額定足夠的電感，電容的耐壓要高於電池電壓，而且要用低內阻（low-ESR）的電容。濾波電容是輔助，不是萬靈丹，前面幾步要先做。
:::

:::case B 有畫面，但 OSD 文字亂跳
1. **影像制式要一致**：Betaflight「OSD」頁的影像格式（Video Format）選 PAL 或 NTSC 時，要和鏡頭輸出的制式相同；不確定時可以先選 Auto。
2. **看影像接線**：鏡頭影像先進飛控、再由飛控接到圖傳，兩個接點都不能鬆。
3. **繞過飛控比較**：斷電後把鏡頭影像線直接接到圖傳。文字消失、畫面穩定了，問題在飛控的 OSD 路徑；畫面本身也在跳，問題在鏡頭或供電。
4. **不要用熱風或高溫工具直接吹 OSD 晶片**：不確定時看文末「還是不行？」。
:::

:::case C 改了影像制式後，畫面慘白、過曝或顏色怪
1. **把鏡頭、飛控、眼鏡的制式改成同一種**。
2. **鏡頭選單恢復預設**：曝光、白平衡一次只改一項，改完看結果再改下一項。
3. **繞過飛控比較**：鏡頭直接接圖傳，確認不是 OSD 疊加造成。
4. **換電源畫面就差很多**：停止測試，檢查供電。
:::

:::checks 怎樣算修好
- 拆槳狀態下慢慢推油門，畫面沒有隨油門出現明顯橫紋（拆槳時電流很小，只算初步確認）
- 實際低空飛行，或用合適的測試架帶負載時，也沒有明顯橫紋
- OSD 文字穩定不跳動，邊緣不閃爍
- 畫面亮度與顏色正常，和鏡頭直接接圖傳時的畫面差不多
:::

:::stop 什麼時候停手
加裝濾波零件後有元件發燙、膨脹，或焊接時碰到旁邊的焊點造成短路：能安全拔掉電池就立刻拔掉，不要再通電，看文末「還是不行？」。元件冒煙或膨脹時不要用手去碰，先遠離觀察，有起火就離開現場並打 119。
:::
