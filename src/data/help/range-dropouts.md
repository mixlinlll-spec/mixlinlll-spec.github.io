:::safety 開始前
距離問題沒解決前，不要往更遠或看不到的地方飛。先照〈失聯保護怎麼確認真的有效〉確認斷控時飛機會照設定停機或返航。
:::

## 先分出是哪一種斷訊

| 斷訊的樣子 | 代表什麼 | 看哪一段 |
| --- | --- | --- |
| 只有畫面變差或斷掉，遙控還能控制 | 圖傳那一路的問題 | A |
| 畫面正常，但出現 RXLOSS 或失控 | 遙控接收那一路的問題 | B |
| 近處正常，飛遠時兩個一起斷 | 兩套天線互相干擾、被遮蔽，或供電不穩 | C |
| 好幾台一起飛時才出現 | 頻道互相干擾 | D |

## 依狀況處理

:::case A 只有圖傳變差
1. **看圖傳天線**：天線有沒有折到、接頭有沒有鬆。受損的天線會讓距離大幅縮短，換一支正常的天線交叉測試最快。
2. **看天線擺位**：飛機上的圖傳天線不要被機架、電池擋住；眼鏡天線要朝向飛行的方向。
3. **看功率設定**：功率要在當地法規允許範圍內。高功率時供電被拉低也會斷圖，這種情況請看文末「還是不行？」。
4. **換場地比較**：在 Wi-Fi 很多、人很多的地方，距離本來就會變短。
:::

:::case B 只有遙控斷訊
1. **看接收機天線**：同軸線有沒有折斷、外皮破損、接頭鬆脫。接收機天線是最容易壞的地方。
2. **看天線方向**：兩支天線盡量互成 90 度，讓飛機轉向時至少一支對得到遙控器；同軸線彎折要緩，不要折成死角。
3. **看遙控器設定**：發射功率與封包率（Packet Rate）。遠距飛行時，較低的封包率可以換到較遠的距離。
:::

:::case C 近處正常，飛遠兩個一起斷
1. **把兩套天線分開**：接收機天線不要和圖傳天線並排或壓在一起。參考做法是至少間隔約 4 公分；圖傳的輸出很強，太近會壓過 2.4G 接收機。
2. **兩套都是 2.4G 時更要注意**：例如 2.4G 遙控配 2.4G 數位圖傳，距離與擺位更要拉開。降低圖傳功率測試，情況明顯改善就是互相干擾。
3. **不要只刷韌體換頻段**：不同頻段需要對應的硬體與天線，也要符合當地規定，不能只靠刷韌體把 2.4G 改成 900M。
4. **兩個仍然一起斷**：可能是供電被拉低，拆槳在地面比較圖傳開啟與關閉時的狀態，接著看文末「還是不行？」。
:::

:::case D 多台同場才出現
1. **類比圖傳先分配頻道**：同場每台用不同頻道，頻道之間拉開，不要用相鄰頻道。
2. **數位圖傳各用不同頻道**：避免全部設成自動。
3. **一台一台加入**：先只開一台的圖傳，再逐台打開，找出是哪兩台衝突。
4. **降低不必要的功率**：近距離飛行不需要開到最大功率。綁定密語只用來區分是哪一台遙控器，不會消除無線干擾。
:::

:::checks 怎樣算修好
- 在同一個場地、同樣高度，距離回到以前的水準
- 飛機轉向時畫面與遙控都不會突然斷掉
- 多台同場時，各台畫面互不干擾
:::

:::stop 什麼時候停手
飛行中出現 RXLOSS、畫面頻繁斷掉，或天線已經明顯損壞：立刻往回飛並降落，找到原因前不要再飛遠。
:::
