:::safety 開始前
距離問題沒解決前，不要往更遠或看不到的地方飛。先照 [[failsafe-check]] 確認斷控時飛機會照設定停機或返航。
:::

{{tool:case-picker}}

## 先分出是哪一種斷訊

| 斷訊的樣子 | 代表什麼 | 看哪一段 |
| --- | --- | --- |
| 只有畫面變差或斷掉，遙控還能控制 | 圖傳那一路的問題 | A |
| 畫面正常，但出現 RXLOSS 或失控 | 遙控接收那一路的問題 | B |
| 近處正常，飛遠時兩個一起斷 | 兩套天線互相干擾、被遮蔽，或供電不穩 | C |
| 好幾台一起飛、或 2.4G 遙控配 2.4G 圖傳時才出現 | 無線互相干擾 | 看 [[radio-interference]] |

## 依狀況處理

:::case A 只有圖傳變差
1. **看圖傳天線**：天線有沒有折到、接頭有沒有鬆。受損的天線會讓距離大幅縮短，換一支正常的天線交叉測試最快。
2. **看天線擺位**：飛機上的圖傳天線不要被機架、電池擋住；眼鏡天線要朝向飛行的方向。
3. **看功率設定**：功率要在當地法規允許範圍內。高功率發射時圖傳會更熱、供電負擔更大，供電被拉低也會斷圖，這種情況請看文末「還是不行？」。
4. **換場地比較**：在 Wi-Fi 很多、人很多的地方，距離本來就會變短。
:::

:::case B 只有遙控斷訊
1. **看接收機天線**：同軸線有沒有折斷、外皮破損、接頭鬆脫。接收機天線是最容易壞的地方。
2. **看天線方向**：有兩支天線的接收機（分集接收），兩支盡量互成 90 度，讓飛機轉向時至少一支對得到遙控器；只有一支天線的接收機，讓天線尾端露出機身、不要被碳纖板擋住。同軸線彎折要緩，不要折成死角。
3. **看遙控器設定**：發射功率與封包率（Packet Rate）。遠距飛行時，較低的封包率可以換到較遠的距離；發射功率同樣要在當地法規允許範圍內。
:::

:::case C 近處正常，飛遠兩個一起斷
1. **把兩套天線分開**：接收機天線不要和圖傳天線並排或壓在一起。參考做法是至少間隔約 4 公分（天線安裝指南的建議值，不是保證值，實際依機架空間而定）；圖傳的輸出很強，太近會壓過接收機。
2. **看遮蔽**：碳纖機架、電池、金屬件擋在天線和你之間，距離會明顯變短。
3. **兩個仍然一起斷**：可能是供電被拉低。拆槳在地面比較圖傳開啟與關閉時的狀態，不要邊飛邊拿電表量，接著看文末「還是不行？」。
:::

:::checks 怎樣算修好
- 在同一個場地、同樣高度，距離回到以前的水準
- 飛機轉向時畫面與遙控都不會突然斷掉
- OSD 上的訊號數值在平常飛行範圍內沒有突然掉到很低
:::

:::stop 什麼時候停手
飛行中出現 RXLOSS、畫面頻繁斷掉，或天線已經明顯損壞：立刻往回飛並降落，找到原因前不要再飛遠。
:::
