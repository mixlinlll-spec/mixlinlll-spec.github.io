:::safety 開始前
有鼓包、變形、異味或發熱的電池不要存放，先看 [[battery-swelling]]。整理電壓時，人要在場，不要讓電池在無人看管時充放電。
:::

## 建議作法

1. **整理到存放電壓**：用充電器的存放（Storage）功能。一般 LiPo 約 3.80V／節，常見 LiHV 約 3.80～3.85V／節；Li-ion 先看原廠規格，詳見 [[battery-types-voltage]]。
2. **不要滿電放好幾週**：長時間滿電存放是鼓包的常見原因之一。
3. **也不要電量太低放著**：拔掉會持續耗電的東西（飛機、蜂鳴器、電壓顯示器）。
4. **放對地方**：放進防火袋或不可燃容器，擺在陰涼乾燥、遠離陽光與熱源的地方，不要放在車上；電池之間不要互相擠壓，平衡頭收好不要外露。
5. **每個月量一次**：看外觀與每一節電壓。

## 看結果判斷

| 看到的狀況 | 代表什麼 | 下一步 |
| --- | --- | --- |
| 每一節都還在存放電壓附近 | 存放狀況正常 | 繼續定期檢查 |
| 某一節明顯比其他節低 | 那一節自放電異常 | 停用，不要充電或補電，看 [[battery-cell-imbalance]] |
| 存放時接著會耗電的東西（飛機、蜂鳴器、電壓顯示器），各節一起往下掉、彼此仍很接近，外觀正常 | 被接著的東西吃掉電量，不是電池本身的問題 | 拔掉耗電的東西。充電器接上不報錯時，人在旁邊用 Storage 功能補回存放電壓，之後照每月檢查；充電器報「電壓過低」就不要硬充，看 [[battery-wont-charge]] |
| 沒有接任何東西，整包仍明顯往下掉，或某一節掉得比其他節多 | 疑似電池內部異常自放電 | 先停用，不要充電或補電；放在不可燃容器裡、遠離可燃物，看 [[battery-cell-imbalance]] 或文末「還是不行？」 |
| 外觀膨脹、變形 | 電池已經受損 | 停止使用，看 [[battery-swelling]] |

:::checks 怎樣算存放正確
- 存放前每一節都在存放電壓附近，彼此差距很小
- 存放一個月後再量，和存放當天的紀錄比較：沒有任何一節明顯掉得比其他節多，整包仍在存放電壓附近，外觀沒有膨脹
- 電池放在防火袋或不可燃容器，遠離熱源與陽光
:::

:::stop 什麼時候停手
存放中發現鼓包、漏液、異味或發熱，或沒有接任何東西卻持續掉電：不要再充放電。發熱或冒煙時不要用手拿，人先遠離觀察；有火勢就離開現場並打 119。
:::
