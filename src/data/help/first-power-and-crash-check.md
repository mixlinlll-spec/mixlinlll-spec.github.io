:::safety 開始前
拆下全部螺旋槳。所有地面測試都在拆槳狀態下進行。
:::

## 依狀況處理

:::case A 新機第一次上電
1. **目視檢查**：焊點有沒有沾錫連在一起、線材有沒有被機架壓到、螺絲有沒有鎖緊、機身裡有沒有異物或碳纖碎屑。
2. **接限流保護器上電**：第一次接電池先經過限流保護器（Smoke Stopper），有短路時它會切斷電流。圖傳先接好天線。
3. **連 Betaflight 檢查**：「設定」頁的 3D 飛機會跟著手轉（陀螺儀正常）、「接收機」頁撥搖桿通道會動、電壓讀數和電池實際電壓接近。
4. **「馬達」頁逐顆測試**：順序與轉向都和畫面圖一致。
5. **測試解鎖與失聯保護**：拆槳狀態下解鎖、上鎖都正常；關掉遙控器時，飛控會進入失聯保護。
6. **裝槳低空試飛**：到空曠處低高度懸停，確認沒有異常震動或往一邊偏。
:::

:::case B 摔機之後
1. **螺旋槳**：每一片看有沒有缺角、裂痕，有疑慮就換掉。
2. **機架**：機臂有沒有裂痕、碳纖有沒有分層、螺絲有沒有鬆。
3. **馬達**：用手轉每顆，沒有卡頓、異音，外殼轉動沒有偏擺（軸彎）。
4. **線材與天線**：接收機天線、圖傳天線座、相機線、焊點有沒有被扯鬆或斷掉。
5. **電池**：外觀有撞擊變形、鼓包，就停止使用。
6. **清掉碳纖碎屑**：碳纖會導電，碎屑卡在電路板上是常見的短路原因。
7. **連 Betaflight**：陀螺儀和各通道都正常，才裝槳試飛。
:::

:::case C 要不要上防水漆？
防水漆（Conformal Coating）是在電路板上塗一層薄薄的絕緣膜，可以擋潮氣、露水、草地的濕氣和碳纖粉塵。

1. **常在潮濕、草地、雪地飛**：建議上。
2. **它不等於可以泡水**：只能抵抗潮氣和噴濺；插頭與按鍵仍然怕水。
3. **要避開的位置**：USB 座、BOOT 按鍵、接頭、氣壓計、相機感光元件、圖傳和接收機的按鍵；接頭先插上再塗。
4. **薄塗**：用刷的、一到兩層就好，每層等乾；建議在組好、測試正常後再塗。
5. **維修時要先清掉**：塗層會讓焊接變困難，維修前要依塗層產品的說明移除。
:::

:::checks 怎樣算修好
- 接限流保護器上電沒有跳，沒有零件發燙
- 「設定」頁 3D 飛機跟著手轉，「接收機」頁通道正常，「馬達」頁順序與轉向正確
- 拆槳關掉遙控器時，飛控有進入失聯保護
- 裝槳低空懸停穩定，沒有異常震動或偏移
:::

:::stop 什麼時候停手
上電時冒煙、有燒焦味、限流保護器跳掉、任何零件幾秒內變燙，或電池變形鼓包：立刻拔掉電池，不要再上電。
:::
