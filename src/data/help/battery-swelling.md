:::safety 開始前
先看電池有沒有發熱、冒煙、有火花或嘶嘶聲。有任何一項，不要用手拿、不要搬運，人先遠離；有火勢就離開現場並打 119。下面的步驟只適用於已經冷卻、沒有冒煙的電池。
:::

## 先看是哪一種狀況

| 看到的狀況 | 代表什麼 | 下一步 |
| --- | --- | --- |
| 冒煙、有火花、嘶嘶聲 | 正在熱失控，可能起火 | 不要碰，人先遠離；有火勢就離開現場並打 119 |
| 鼓包而且發熱（看得到冒熱氣、聞到異味，或手背靠近就感覺得到熱），或越來越燙 | 有起火風險 | 不要用手拿，人保持距離觀察，可以安全拔掉的線才拔；等完全冷卻再處理 |
| 鼓包但不熱、沒有異味 | 電池已經受損 | 停止使用，依下面的步驟處理 |
| 沒有鼓包，但有甜味、化學味等異味 | 可能有漏液或內部受損 | 停止使用，依下面的步驟處理 |
| 外觀撞擊變形、外皮破損 | 內部可能受損 | 停止使用，依下面的步驟處理 |
| Li-ion 電池組（18650／21700）：電芯凹陷、熱縮套破損露出金屬殼、端子有白色結晶或液體、鎳片焦黑變色 | 鋼殼電芯很少整顆鼓起，這些才是常見的受損徵兆；露出金屬殼有短路風險 | 停止使用，依下面的步驟處理 |

## 已冷卻、沒有冒煙的電池怎麼處理

1. **停止充放電**：不要再拿去充電或飛行，也不要試著「壓回去」。
2. **放進不可燃的容器**：放到防火袋或不可燃的容器裡，擺在通風、遠離可燃物的地方，再觀察一段時間。
3. **不要自己處理內部**：不要戳破放氣、不要短接、不要泡鹽水，也不要為了回收強制放電到零伏。
4. **絕緣後回收**：確定不再發熱、狀態穩定後，把端子用膠帶絕緣，交給可回收鋰電池的地方（例如詢問當地清潔隊、電池回收業者或購買的店家）。有漏液的電池不要丟進一般回收箱，先繼續放在不可燃容器裡、擺在室外通風處，再詢問回收單位的收受方式。
5. **找出原因**：檢查當初的充電設定與存放方式，避免下一顆電池重蹈覆轍。長時間滿電放著是常見原因之一，存放方式看 [[battery-storage]]。

:::checks 怎樣算處理完成
- 受損電池已經停止使用，放在不可燃的容器裡
- 端子已用膠帶絕緣，並交給可回收鋰電池的地方
- 已檢查充電器的電池種類設定與存放方式，下一顆電池不重蹈覆轍
:::

:::stop 什麼時候停手
電池冒煙、起火、有火花或持續變燙：不要碰、不要搬運，人立刻遠離；有火勢就離開現場並打 119。
:::
