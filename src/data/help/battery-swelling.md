:::safety 不要再充電、不要刺破
鼓包或受損的電池可能起火。不要充電、不要擠壓或刺破，也不要丟一般垃圾。
:::

## 常見原因
- 過充、過放
- 摔機撞擊
- 長時間滿電或高溫存放

## 檢查步驟
1. **馬上停用**：拔掉充電器或飛機。
2. **移到安全的地方**：放在防火袋、金屬盒或不可燃的容器裡，遠離可燃物，放在戶外或通風處。
3. **觀察**：持續發熱、冒煙時，遠離電池，必要時打 119。
4. **回收**：依當地規定送到電池回收點，或聯絡 EWP 詢問。

:::checks 怎樣算修好
- 受損電池已停用，並放在安全的容器裡等待回收
- 已依當地規定送回收，或已聯絡 EWP 處理
:::

:::stop 什麼時候停手
這篇的電池都不應再使用。冒煙、起火時不要靠近，先確保人員安全。
:::
