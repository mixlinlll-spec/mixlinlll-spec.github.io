:::safety 開始前
發現鼓包、變形、異味、撞傷或發熱，先停止充電和放電。不要擠壓、刺穿、折彎電池。
:::

{{tool:case-picker}}

## 依狀況處理

:::case A 電池鼓包、變形或有異味
1. **移到安全位置**：放到通風、遠離可燃物、可以隔離的地方，例如防火袋或不可燃的容器裡，觀察一段時間。
2. **不要自己處理內部**：不要戳破放氣、不要短接、不要泡鹽水，也不要為了回收強制放電到零伏。
3. **確定安全再回收**：不再發熱、狀態穩定後，把端子用膠帶絕緣，依回收端的要求處理。有漏液或持續發熱時，不要拿去一般回收箱。
4. **找出原因**：檢查當初的充電設定與存放方式，避免下一顆電池重蹈覆轍（例如長時間滿電放著）。
:::

:::case B 長期不飛，要怎麼存放
1. **整理到存放電壓**：用充電器的存放功能。一般 LiPo 約 3.80V／節，常見 LiHV 約 3.80～3.85V／節；Li-ion 先看原廠規格，詳見〈LiPo、LiHV、Li-ion 怎麼分〉。
2. **不要滿電放好幾週**：長時間滿電存放是鼓包的主要原因之一。
3. **也不要電量太低放著**：拔掉會持續耗電的東西（飛機、蜂鳴器、電壓顯示器）。
4. **放對地方**：陰涼乾燥、遠離陽光與熱源，不要放在車上；電池之間不要互相擠壓，平衡頭收好不要外露。
5. **每個月量一次**：看外觀與每一節電壓，持續掉電或某一節明顯落後就停用。
:::

## 看結果判斷

| 看到的狀況 | 代表什麼 | 下一步 |
| --- | --- | --- |
| 輕微膨脹但不熱 | 電池已經受損 | 停止使用，依 A 段處理 |
| 鼓包且持續發熱或有異味 | 有起火風險 | 立刻移到戶外、遠離可燃物，不要搬進室內 |
| 存放一個月後某一節明顯變低 | 那一節自放電異常 | 停用 |
| 存放後每節電壓都還在存放電壓附近 | 存放狀況正常 | 繼續定期檢查 |

:::checks 怎樣算存放正確
- 存放前每一節都在存放電壓附近
- 存放一個月後再量，電壓變化很小，外觀沒有膨脹
- 電池放在防火袋或不可燃容器，遠離熱源與陽光
:::

:::stop 什麼時候停手
鼓包、漏液、冒煙、有異味或持續發熱：不要再充放電，也不要放在室內或車上，移到戶外遠離建築物與可燃物的地方觀察。
:::
