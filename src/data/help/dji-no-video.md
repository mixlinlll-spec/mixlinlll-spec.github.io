:::safety 開始前
拆下螺旋槳。天空端在地面通電會發熱，測試時間盡量短，旁邊放一台風扇吹。不要在通電時插拔天空端的排線或鏡頭線。
:::

## 先看天空端的燈

| 看到什麼 | 代表什麼 | 看哪一段 |
| --- | --- | --- |
| 眼鏡本身沒有開機畫面或選單 | 眼鏡沒電或沒開機，先處理眼鏡 | 先充電、重開眼鏡 |
| 天空端燈完全不亮 | 最常見是沒有供電或電壓不足；也可能是接頭沒插好或天空端損壞 | A |
| 天空端紅燈，眼鏡沒畫面 | 天空端有電，但還沒和眼鏡連上 | 看 [[dji-pairing-activation]] |
| 一開始有畫面，在地上放一陣子才黑 | 多半和散熱有關 | B |
| 換線、摔機後黑屏、彩塊或時好時壞 | 鏡頭排線或接頭問題 | C |

## 依狀況處理

:::case A 天空端燈不亮
1. **看型號再看電壓**：O4 Air Unit 的輸入電壓是 3.7–13.2V，O4 Air Unit Pro 是 7.4–26.4V（DJI 官方規格）。一般 O4 不能直接接 4S 或 6S 電池的電壓。供電細節看 [[dji-o4-power-wiring]]。
2. **看接在哪個焊點**：天空端的電源線接在飛控的 9V 或 5V 供電焊點、或直接接電池，對照上一步的範圍。O4 Pro 最低要 7.4V，接到 5V 焊點不會開機。有些飛控的 9V 輸出要在設定裡打開開關（PINIO）才有電，量測方式看 [[dji-o4-power-wiring]] 的「通電前怎麼量供電」。
3. **曾經接到超過範圍的電壓**：不要再反覆通電測試，直接看文末「還是不行？」。
:::

:::case B 靜置一陣子才黑屏
1. **先讓它冷卻**：斷電放涼後再開，馬上又有畫面，很可能是地面過熱保護（DJI 說明待機溫度過高時會自動關機）。
2. **地上待機時開低功耗模式**：O4 系列有地面低功耗模式，不需要在地上錄影時建議打開。DJI 官方數據（25°C 環境）：開啟後一般 O4 Air Unit 最多可待機約 2.5 分鐘，O4 Air Unit Pro 約 20 分鐘。環境溫度高於 25°C 時，官方建議用風扇等外部方式散熱。
3. **看散熱有沒有被擋住**：外殼、固定座或線材有沒有蓋住散熱面，裝機時要讓飛行時的氣流吹得到天空端。
4. **冷機也黑屏，或摸起來燙到不敢碰**：停止測試，看文末「還是不行？」。
:::

:::case C 換線或摔機後黑屏、彩塊、時好時壞
1. **斷電後再檢查**：拔掉電池與 USB，兩端排線接頭有沒有完全插到底、有沒有翹邊或座子破裂。
2. **用對的線**：O4 和 O4 Pro 各有相容的鏡頭同軸線，不能只看長度或外觀判斷能不能用。
3. **看線有沒有被拉扯**：鏡頭轉動時，排線有沒有被夾住、急折或拉緊。
4. **換一條同規格的正常線比較**：換線就好，問題在原本的線；還是一樣，可能是接座或鏡頭。
:::

:::checks 怎樣算修好
- （A）天空端綠燈恆亮，眼鏡畫面清楚
- （B）在地上有風扇輔助散熱、待機時間不超過官方數據（一般 O4 約 2.5 分鐘、O4 Pro 約 20 分鐘）時，畫面不會黑掉（實際能待機多久依環境溫度與安裝方式而異）
- （C）輕輕轉動鏡頭角度，畫面不會閃彩塊或中斷
:::

:::stop 什麼時候停手
天空端接過超過規格的電壓，或冒煙、有燒焦味：不要用手去碰天空端；能安全拔掉電池就拔掉，然後遠離觀察，有起火就離開現場並打 119。排線接座破裂時也不要再硬插。
:::
