## 常見原因
- 天空端沒有供電，或沒有配對
- 鏡頭同軸線鬆脫或損壞
- 放在地上太久過熱

## 檢查步驟
1. **天空端燈不亮**：插電池後燈完全不亮，可能沒有供電，請交給 EWP 檢查接線。
2. **紅燈**：天空端和眼鏡沒有配對，看[[dji-pairing-activation]]。
3. **綠燈但黑屏**：斷電後把鏡頭同軸線兩端重新插到底。O4 和 O4 Pro 的同軸線是共用的；手上的線來源不明時，換一條標示 O4／O4 Pro 的線比較。
4. **放一會才黑屏**：在地上不要放太久，或開啟眼鏡的地面低功耗模式，必要時用風扇吹。

:::checks 怎樣算修好
- 天空端綠燈，眼鏡畫面清楚
- 輕轉鏡頭角度時，畫面不會閃斷
:::

:::stop 什麼時候停手
天空端燙到不敢碰、有焦味，或冷機時也一直黑屏：停用，交給 EWP 檢測。
:::
