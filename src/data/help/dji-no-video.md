:::safety 開始前
拆下螺旋槳。天空端在地面通電會發熱，測試時間盡量短，旁邊放一台風扇吹。不要在通電時插拔天空端的排線或鏡頭線。
:::

## 先看天空端的燈

| 看到什麼 | 代表什麼 | 看哪一段 |
| --- | --- | --- |
| 眼鏡本身沒有開機畫面或選單 | 眼鏡沒電或沒開機，先處理眼鏡 | 先充電、重開眼鏡 |
| 天空端燈完全不亮 | 天空端沒有供電 | A |
| 天空端紅燈，眼鏡沒畫面 | 天空端有電，但還沒和眼鏡連上 | B |
| 天空端綠燈恆亮 | 已經和眼鏡連上 | 有畫面就正常；沒畫面看 D |
| 一開始有畫面，在地上放一陣子才黑 | 多半和散熱有關 | C |
| 換線、摔機後黑屏、彩塊或時好時壞 | 鏡頭排線或接頭問題 | D |
| 電腦的 DJI Assistant 2 找不到裝置 | 線材、插孔或軟體版本問題 | E |

## 依狀況處理

:::case A 天空端燈不亮
1. **看型號再看電壓**：O4 Air Unit 的輸入電壓是 3.7–13.2V，O4 Air Unit Pro 是 7.4–26.4V（DJI 官方規格）。一般 O4 不能直接接 4S 或 6S 電池的電壓。
2. **看接在哪個焊點**：天空端的電源線接在飛控的 9V 或 5V 供電焊點、或直接接電池，對照上一步的範圍。
3. **曾經接到超過範圍的電壓**：不要再反覆通電測試，直接看文末「還是不行？」。
:::

:::case B 紅燈，和眼鏡連不上
1. **兩邊都更新到相容版本**：版本差太多時會配不上，用 DJI Assistant 2 把眼鏡和天空端都更新。
2. **眼鏡選對裝置**：Goggles 3 在「狀態 → 切換」選擇你用的天空端型號（例如 O4 Air Unit 或 O4 Air Unit Pro）。
3. **進入配對**：Goggles 3 按住電源鍵到發出嗶聲；Goggles 2／Integra 按鏡片中間的配對鍵。接著用鑷子按一下天空端的配對鍵，紅燈會變成慢閃。
4. **正常結果**：天空端變成綠燈恆亮，眼鏡出現畫面。兩邊距離保持約 0.5–1 公尺，附近不要有其他人同時在配對。
:::

:::case C 靜置一陣子才黑屏
1. **先讓它冷卻**：斷電放涼後再開，馬上又有畫面，就是地面過熱保護。
2. **地上待機時開低功耗模式**：O4 系列有地面低功耗模式，不需要在地上錄影時建議打開；環境溫度明顯高於 25°C 時，用風扇輔助散熱。
3. **看散熱有沒有被擋住**：外殼、固定座或線材有沒有蓋住散熱面，裝機時要讓飛行時的氣流吹得到天空端。
4. **冷機也黑屏，或某處燙到不敢碰**：停止測試，看文末「還是不行？」。
:::

:::case D 換線或摔機後黑屏、彩塊、時好時壞
1. **斷電後再檢查**：拔掉電池與 USB，兩端排線接頭有沒有完全插到底、有沒有翹邊或座子破裂。
2. **用對的線**：O4 和 O4 Pro 各有相容的鏡頭同軸線，不能只看長度或外觀判斷能不能用。
3. **看線有沒有被拉扯**：鏡頭轉動時，排線有沒有被夾住、急折或拉緊。
4. **換一條同規格的正常線比較**：換線就好，問題在原本的線；還是一樣，可能是接座或鏡頭。
:::

:::case E DJI Assistant 2 找不到裝置
1. **換一條能傳資料的 USB 線**，直接插電腦本身的 USB 孔，不要經過集線器。
2. **用支援 O4 的版本**：使用 DJI Assistant 2（Consumer Drones Series）並登入 DJI 帳號。
3. **啟用要接電池**：O4 系列啟用時要用電池或規格內的電源供電，只插 USB-C 線無法啟用；啟用也不能在 DJI Fly App 完成。
4. **更新過程不要拔線**，並保持散熱。
:::

:::checks 怎樣算修好
- 天空端綠燈恆亮，眼鏡畫面清楚
- 在地上通電 3 分鐘、旁邊有風扇時，畫面不會黑掉
- 輕輕轉動鏡頭角度，畫面不會閃彩塊或中斷
:::

:::stop 什麼時候停手
天空端接過超過規格的電壓、冒煙、有燒焦味，或燙到無法觸碰：立刻拔掉電池，不要再通電。排線接座破裂時也不要再硬插。
:::
