## 常見原因
- 電池老化或某一節變弱
- 天氣冷，電池溫度太低
- 飛機變重、槳或馬達損壞讓耗電變大

## 檢查步驟
1. **量每一節電壓**：充飽靜置後差很多，看[[battery-cell-imbalance]]。
2. **冷天先保溫**：起飛前把電池放在口袋或保溫袋，起飛後先溫和飛一下。
3. **換一顆電池比較**：同一台飛機換電池就正常，問題在電池。
4. **看飛機**：換新槳，檢查馬達是否順暢、有沒有加裝太重的配件。

:::checks 怎樣算修好
- 正常溫度下，飛行時間回到這顆電池以前的水準
- 充飽靜置後，每節電壓相近
:::

:::stop 什麼時候停手
電池鼓包、飛完異常發燙，或某一節明顯掉得比較快：停止使用這顆電池，看[[battery-swelling]]。
:::
