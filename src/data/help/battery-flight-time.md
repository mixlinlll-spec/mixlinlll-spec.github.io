:::safety 開始前
續航變短時不要硬飛到警告響才回來。先保守提早降落，查清楚原因再恢復原本的飛法。
:::

## 依狀況處理

:::case A 平常天氣，續航突然變短
1. **量每一節電壓**：充飽靜置約十分鐘後量。一般 LiPo／LiHV 節與節之間差距超過約 0.05V 就要注意（參考值，條件與 Li-ion 的差別看 [[battery-cell-imbalance]]）。
2. **看是不是平衡充**：充電器要用平衡充模式充飽，不是只充到某個總電壓就停。
3. **看電池年紀**：循環次數多、用很久的電池容量本來就會下降。鼓包或外皮變形的電池要停用。
4. **看飛機有沒有變重、變耗電**：換了比較重的電池、加了攝影機、換了不同的槳，都會變短。用手轉每一顆馬達，有卡卡或沙沙聲也會增加耗電。
5. **看電壓讀數準不準**：飛控的電壓讀數和電表差很多，會讓你誤判續航。
:::

:::case B 冷天續航變差，一推油門電壓就掉
低溫會讓電池內阻上升，這是正常的物理現象，可以減輕，但沒辦法完全消除。

1. **飛前保溫**：電池放在保溫袋裡，接近常溫再飛，不要從冷車上直接拿出來用。電池還很冷，或剛飛完還燙時，也不要馬上充電，先回到室溫。
2. **第一顆電池先溫和地飛**：電池已經冷到接近 0°C 時不要起飛，先保溫回到常溫；讓電池自己慢慢熱起來，再正常操作。
3. **提早回收**：冷天要預期續航變短，比平常更早降落。
4. **天氣回暖還是一樣**：可能是電池本身老化，回到 A 段檢查。
:::

## 看結果判斷

| 看到的狀況 | 代表什麼 | 下一步 |
| --- | --- | --- |
| 每次都是同一節特別低 | 那一節變弱 | 看 [[battery-cell-imbalance]] |
| 每節都差不多，但整體掉得快 | 電池整體老化 | 考慮退役，飛行時提早降落 |
| 只有天冷時變差 | 低溫讓內阻上升 | 飛前保溫、提早回收 |
| 換一顆新電池也一樣短 | 飛機本身變耗電 | 秤全機重量和以前比較；換一組新槳；斷電用手轉每顆馬達，有卡頓或沙沙聲的那顆先處理，看 [[motor-heat-noise]] |

:::checks 怎樣算修好
- 充飽靜置約十分鐘後，每一節電壓的最大差距在約 0.05V 以內（一般 LiPo／LiHV 的參考值，看 [[battery-cell-imbalance]]）
- 用正常電池、同樣的飛法，續航回到過去差不多的時間
- 冷天保溫後飛行，推油門時電壓不會一下子掉到要降落的程度
:::

:::stop 什麼時候停手
電池鼓包、外皮變形、飛完異常發燙，或某一節反覆明顯落後：停止使用這顆電池。電池發熱、冒煙或有火花時不要用手拿、不要搬運，人先遠離觀察；有火勢就離開現場並打 119。不要在低溫下追求極限續航，過放會造成永久損傷。
:::
