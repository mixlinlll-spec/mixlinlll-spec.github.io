:::safety 開始前
拆下全部螺旋槳。這個問題沒排除前不要起飛：飛行中接收機重啟會直接失控。
:::

## 建議檢查順序

1. **比較兩種供電**：只接 USB 時看接收機燈號；再接上電池，看燈號是否開始重新閃（代表接收機重啟了）。
2. **看接收機供電接在哪**：官方接線說明是接收機的 5V 接飛控的 5V（或 4.5V）焊點、地線接到地線焊點。焊點鬆動、地線接觸不良，插電池時容易重啟。
3. **拔掉圖傳測試**：斷電後先暫時拔掉圖傳再試。拔掉後不再重啟，代表圖傳啟動時把供電拉低，需要分開檢查供電。
4. **不要自己把兩路供電接在一起**：仍然會重啟，看文末「還是不行？」。

## 看結果判斷

| 看到的情況 | 代表什麼 | 下一步 |
| --- | --- | --- |
| 只接 USB 正常，接電池時燈號重新閃 | 電池供電時接收機重啟 | 檢查接收機電源與地線焊點 |
| 拔掉圖傳後不再重啟 | 圖傳啟動拉低供電 | 檢查圖傳供電接法，送修評估 |
| 動一動線就重啟 | 焊點或線材接觸不良 | 斷電後重新焊接或更換線材 |
| 接電池後接收機或飛控發燙 | 可能有短路或供電錯誤 | 看下方「什麼時候停手」 |

:::checks 怎樣算修好
- 接上電池後，接收機燈號維持恆亮，不再重新閃
- 拆槳狀態下解鎖、推一點油門，接收機燈號仍然維持恆亮
- 插拔電池多次，每次都能正常連線
:::

:::stop 什麼時候停手
飛行中曾經掉線或重啟：立刻停飛。接上電池時接收機或飛控冒煙、有焦味：不要用手去碰發燙的零件；能安全拔掉電池就拔掉，然後遠離觀察，有起火就離開現場並打 119。
:::
