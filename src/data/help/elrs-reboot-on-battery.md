:::safety 開始前
拆下全部螺旋槳。這個問題沒排除前不要起飛：飛行中接收機重啟會直接失控。
:::

## 建議檢查順序

1. **比較兩種供電**：只接 USB 時看接收機燈號；再接上電池，看燈號是否開始重新閃（代表接收機重啟了）。
2. **看接收機供電接在哪**：官方接線說明是接收機的 5V 接飛控的 5V（或 4.5V）焊點、地線接到地線焊點。焊點鬆動、地線接觸不良，插電池時容易重啟。
3. **拔掉圖傳測試**：斷電後先暫時拔掉圖傳再試。拔掉後不再重啟，比較可能是圖傳和接收機共用同一路供電，圖傳開機時把電壓拉低。看飛控接線圖：接收機和圖傳是不是接在同一個 5V（或 9V）焊點；可以的話，讓接收機改接飛控上另一個 5V 焊點（依飛控接線圖，不要接到電池電壓）。
4. **仍然會重啟**：看文末「還是不行？」。不要自己把圖傳和接收機的供電並聯，也不要把接收機改接到電池電壓。

## 看結果判斷

| 看到的情況 | 代表什麼 | 下一步 |
| --- | --- | --- |
| 只接 USB 正常，接電池時燈號重新閃 | 電池供電時接收機重啟 | 斷電後用放大鏡看接收機 5V 與 GND 焊點有沒有裂開、虛焊（焊點應該光亮、包住線頭）；再拆槳、接電池，電表切到直流電壓（V）檔，黑棒碰飛控的 GND 焊點，紅棒碰該零件的電源焊點，讀數約 5V（有些飛控標 4.5V） |
| 拔掉圖傳後不再重啟 | 圖傳開機時把共用的供電拉低 | 讓接收機和圖傳不要共用同一個供電焊點（依飛控接線圖）；改不了或不確定，看文末「還是不行？」 |
| 動一動線就重啟 | 焊點或線材接觸不良 | 斷電後重新焊接或更換線材 |
| 接電池後接收機或飛控發燙 | 可能有短路或供電錯誤 | 看下方「什麼時候停手」 |

:::checks 怎樣算修好
- 接上電池後，接收機燈號維持恆亮，不再重新閃
- 拆槳狀態下解鎖、推一點油門，接收機燈號仍然維持恆亮
- 插拔電池多次，每次都能正常連線
:::

:::stop 什麼時候停手
飛行中曾經掉線或重啟：立刻停飛。接上電池時接收機或飛控冒煙、有焦味：不要用手去碰發燙的零件；能安全拔掉電池就拔掉，然後遠離觀察，有起火就離開現場並打 119。
:::
