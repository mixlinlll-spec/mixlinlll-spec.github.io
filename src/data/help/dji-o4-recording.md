:::safety 開始前
拆下螺旋槳。讀取或刪除檔案前，先把需要的影片備份到電腦。
:::

## 依狀況處理

:::case A 飛完才發現沒有錄影
1. **確定錄影有啟動**：在眼鏡上方選單按錄影；也可以在眼鏡的相機設定裡打開解鎖自動錄影（選單位置依眼鏡型號與韌體版本而異）。解鎖自動錄影要靠飛控經由 TX／RX 線把解鎖狀態傳給天空端，這條線沒接好時不會作用，看 [[dji-no-osd]]。錄影中畫面會有錄影指示。
2. **看空間**：一般 O4 內建約 23GB，滿了就會停止錄影，要定期把影片搬到電腦。
3. **正常關機再斷電**：停止錄影、等寫入完成後再拔電池，寫到一半斷電容易讓那一段檔案損壞。
4. **用電腦讀檔**：用 USB 接電腦讀取，不要只在眼鏡裡瀏覽就判斷沒有檔案。
5. **經常損壞**：更新韌體，並檢查天空端供電是否穩定。
:::

:::case B 找不到記憶卡
1. **看型號**：依 DJI 官方規格，一般 O4 Air Unit 不支援記憶卡，只有內建 23GB；O4 Air Unit Pro 支援 microSD（最大 512GB），內建 4GB。
2. **分清楚是哪一張卡**：眼鏡的記憶卡和 O4 Pro 天空端的記憶卡是兩張不同的卡。
3. **O4 Pro 換卡測試**：換一張高速卡，備份後在裝置裡格式化，短錄一段再回放。
4. **檔案被切成好幾段是正常的**：O4 Pro 存在記憶卡上的長片會自動分成好幾段檔案（記憶卡檔案大小限制），匯入剪輯軟體時照順序接起來即可。
:::

:::case C 錄影有果凍、畫面抖
1. **先比較兩種錄影**：眼鏡錄影卡頓是無線訊號問題；機載原片有果凍是機身震動。
2. **檢查震動來源**：斷電後換一組完好的槳，檢查馬達軸、機臂和鏡頭固定螺絲。
3. **排線不要繃緊**：鏡頭同軸線要留一點活動空間，繃緊的線會把震動直接傳到鏡頭。
4. **防震座不是越軟越好**：一次只改一個地方（固定方式或防震設定），再比較結果。
5. **後製防震**：O4 有內建 RockSteady 錄影防震；要用 Gyroflow 後製時，Oscar Liang 建議比例 4:3、廣角，並關閉錄影防震，保留原始檔。
:::

:::checks 怎樣算修好
- （A）短錄 30 秒後，用電腦可以讀到並正常播放
- （B）O4 Pro：記憶卡在裝置內格式化後可以正常錄影與回放
- （C）同一條航線再錄一次，機載原片的果凍明顯減少（相關檢查也可以看 [[vibration-jello]]）
:::

:::stop 什麼時候停手
記憶卡槽變形、卡片插不進去或拔不出來：不要硬插硬拔。天空端錄影時燙到無法觸碰：先停止錄影並斷電冷卻。
:::
