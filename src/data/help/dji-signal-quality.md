:::safety 開始前
不要使用來路不明的檔案或工具修改地區、解鎖功率。發射功率與可用頻道受所在地法規限制，請依規定使用。
:::

## 建議檢查順序

1. **天空端有沒有啟用**：新的 O4 系列要先用電腦的 DJI Assistant 2（Consumer Drones Series）登入 DJI 帳號完成啟用，沒啟用時無法發揮完整性能。啟用時天空端要接電池或規格內的電源，只插 USB-C 線不行。
2. **是不是還在地面低功耗**（地面測試時旁邊放風扇散熱，測試時間盡量短）：O4 在地面待機可以開低功耗模式。如果飛起來後功率還是低，通常是飛控沒有把「已解鎖」的狀態傳給圖傳，請看 [[dji-no-osd]] 檢查文字資料線。
3. **天線**：眼鏡天線裝好、朝向飛機的方向；飛機上的天線不要被碳纖機架或電池擋住，也不要折到。
4. **環境**：人多、Wi-Fi 很多的場地干擾大，換一個空曠處比較。
5. **頻寬與畫質**：在眼鏡的傳輸設定把頻寬或畫質降一級，看卡頓有沒有改善。

## 看結果判斷

| 看到什麼 | 代表什麼 | 下一步 |
| --- | --- | --- |
| 選單有些項目反灰進不去、功率很低 | 天空端可能還沒啟用 | 第 1 步，完成啟用後再更新兩邊韌體 |
| 地上很弱，飛起來才正常 | 地面低功耗在運作，屬於正常 | 不需要處理 |
| 飛起來還是很弱 | 可能是圖傳沒收到解鎖狀態（玩家社群常見經驗，DJI 未正式說明） | 檢查飛控到天空端的 TX／RX 線與「連接埠」頁設定，看 [[dji-no-osd]] |
| 能選的頻道只有一個 | 頻寬設得比較寬 | 依 DJI 規格，5.8GHz 在 40／60MHz 頻寬時只有 1 個頻道，20／10MHz 時有 3 個；需要和別人錯開時改用窄頻寬 |
| 遠一點或轉向某個方向就卡 | 天線被遮擋或方向不對 | 第 3 步，調整天線位置後再比較 |
| 降低頻寬後就順了 | 原本訊號邊緣不足 | 在這個場地維持較窄的頻寬 |

:::checks 怎樣算修好
- 眼鏡選單所有項目都可以進入
- 在同一個場地、同樣距離飛一圈，畫面不再明顯卡頓或出現馬賽克
- 和別人同場時，各自在不同頻道上，互不干擾
:::

:::stop 什麼時候停手
天空端燙到無法觸碰、畫面突然全黑後要很久才恢復：先降落並斷電冷卻；反覆發生就停止使用，看文末「還是不行？」。
:::
