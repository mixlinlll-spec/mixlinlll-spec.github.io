## 常見原因
- 天線被機架、電池擋住，或天線損壞
- 天空端還沒啟用，或眼鏡的功率、地區設定被限制
- 現場干擾多

## 檢查步驟
1. **看天線**：天線外皮與接頭完整，尾端伸出機身，不要被碳纖板擋住。
2. **確認已啟用**：天空端與眼鏡都要先啟用，看[[dji-pairing-activation]]。
3. **換頻道或頻寬**：在眼鏡設定把頻寬調小，傳輸會比較穩。
4. **在空曠處比較**：換一個人少、Wi-Fi 少的地方飛，比較是不是環境干擾。

:::checks 怎樣算修好
- 同樣距離下，畫面不再頻繁卡頓或出現馬賽克
- 眼鏡顯示的訊號格數穩定
:::

:::stop 什麼時候停手
畫面一直斷訊時，不要繼續飛遠，先在近處降落。功率與頻道請遵守當地法規。
:::
