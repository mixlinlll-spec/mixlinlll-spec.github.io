:::safety 先拔電池
摔機後第一件事是上鎖、拔電池。不要在電池接著時徒手撿飛機或撥槳。
:::

## 常見問題
- 螺旋槳斷裂、變形
- 機臂裂開、螺絲鬆脫
- 馬達卡沙、軸彎；天線斷掉或接頭鬆脫

## 檢查步驟
1. **槳**：有缺角、裂痕、變形就換新，不要繼續用。
2. **機架**：機臂有沒有裂痕，用手搖一搖有沒有鬆動。
3. **馬達**：拆槳後用手轉，要順、沒有卡沙聲；看外殼有沒有歪。
4. **天線、鏡頭**：天線外皮與接頭完整；鏡頭沒有破裂、排線有插好。
5. **拆槳上電**：電調開機音正常、沒有異味，眼鏡畫面正常，才裝槳試飛。

:::checks 怎樣算修好
- 槳、機臂、馬達、天線外觀都完好
- 拆槳上電一切正常，低空懸停沒有異常抖動或聲音
:::

:::stop 什麼時候停手
冒煙、焦味、馬達轉不動或燙手、電池變形：停止使用，交給 EWP 檢測。電池摔過要另外看[[battery-swelling]]。
:::
