:::safety 開始前
先拔掉電池再檢查。電池如果撞到變形、發熱或冒煙，不要用手拿，先遠離並觀察，處理方式看 [[battery-swelling]]。
:::

## 建議檢查順序

1. **螺旋槳**：每一片看有沒有缺角、裂痕，有疑慮就換掉。
2. **機架**：機臂有沒有裂痕、碳纖有沒有分層、螺絲有沒有鬆。
3. **馬達**：用手轉每顆，轉起來順、沒有卡頓或異音，外殼轉動時不會偏擺（軸沒有彎）。
4. **線材與天線**：接收機天線、圖傳天線座、相機線、焊點有沒有被扯鬆或斷掉。
5. **電池**：外觀有撞擊變形、鼓包，就停止使用。
6. **清掉碳纖碎屑**：碳纖會導電，碎屑卡在電路板上可能造成短路。
7. **拆槳、先接限流保護器上電**：摔機後碳纖碎屑或擠壓過的線材可能短路，第一次上電先經過限流保護器（Smoke Stopper），沒有異常再拿掉。接了數位圖傳（DJI O4 等）時，限流器可能讓它開不起來或燈一直亮，這不一定是短路，詳見 [[power-wiring]]。
8. **拆槳連 Betaflight**：陀螺儀和各通道正常、「馬達」頁每顆都能順轉，才裝槳試飛。

## 看結果判斷

| 看到的狀況 | 代表什麼 | 下一步 |
| --- | --- | --- |
| 馬達轉起來卡卡或有沙沙聲 | 軸承或內部有異物、損傷 | 看 [[motor-heat-noise]] |
| 飛起來抖動、錄影果凍變嚴重 | 槳、馬達或相機固定有損傷 | 看 [[vibration-jello]] |
| 插電池沒反應或接上就重啟 | 供電線或焊點受損 | 看 [[power-wiring]] |
| 眼鏡沒有畫面 | 天線、相機線或圖傳受損 | 類比看 [[analog-no-video]]，DJI 看 [[dji-no-video]] |

:::checks 怎樣算修好
- 螺旋槳、機架、馬達、線材都沒有可見損傷
- 拆槳狀態下「設定」頁 3D 飛機跟著手轉，「馬達」頁每顆都能順轉
- 裝槳低空懸停穩定，沒有新的震動或偏移
:::

:::stop 什麼時候停手
機架斷裂、馬達卡死、上電時有零件冒煙或很快變燙：不要再上電。電池變形、發熱或冒煙時不要用手拿，先遠離觀察，有火勢就離開現場並打 119。
:::
