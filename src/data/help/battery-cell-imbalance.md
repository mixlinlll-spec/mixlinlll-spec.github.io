:::safety 開始前
電表切到直流電壓（V）檔，不要用電流檔。量單節時，兩支探棒各碰一根相鄰的針腳；同一支探棒的金屬尖端不要同時碰到兩根針腳，會造成短路。電池有鼓包、異味或發熱，直接停用。
:::

## 建議檢查順序

1. **平衡充飽後靜置約十分鐘**：再量每一節電壓。剛充完的電壓會稍微回落，靜置後才準。
2. **先排除平衡頭**：看針腳有沒有氧化、歪掉，插到底後再量一次。也可以用另一台充電器或可靠的電壓表比對。
3. **記錄是不是同一節**：連續幾次都是同一節特別低，才是電池本身的問題。
4. **飛完再量一次**：落地後馬上量，再靜置一下量一次，看是不是同一節下降特別快。

## 看結果判斷

表中的 0.05V、0.1V 是本站給一般 LiPo／LiHV 在**充飽或存放電壓、靜置後**量測的參考值，用來決定要不要多注意，不是所有電池種類、所有電量狀態下的故障標準。電量很低或剛飛完還沒靜置時，各節落差會看起來比較大；Li-ion 在低電量區的電壓曲線比較陡，同樣的容量差會顯示成比較大的壓差；沒有平衡線的電池組沒辦法平衡充，落差也會慢慢累積。請以同一顆電池前後比較、以及原廠說明為準。

| 看到的狀況 | 代表什麼 | 下一步 |
| --- | --- | --- |
| 換一台充電器或重插後就正常 | 平衡頭接觸不良 | 清理或更換平衡頭 |
| 靜置後落差約 0.05V（參考值） | 可能開始不平衡，要注意 | 每次都用平衡充，持續記錄 |
| 落差超過約 0.1V（參考值），而且每次都是同一節 | 那一節很可能已經變弱 | 建議停用；再配合內阻、放著是否掉電一起判斷 |
| 平衡充一直卡在最後，某一節追不上 | 充電器平衡能力有限，或那一節異常 | 依充電器規格降低充電電流觀察，差距沒有縮小就停用 |
| 同一節放著也一直掉電、或充電時特別熱 | 電芯異常 | 立刻停用 |

## 為什麼總電壓正常，還是會有弱的那一節？

很多飛控和眼鏡顯示的「每節電壓」，其實是總電壓除以節數算出來的平均值，看不到最弱的那一節。所以飛行中畫面看起來還有電，最弱的那一節可能已經過低。

- 落地後量每一節並記錄，和同樣飛法的過去紀錄比較。
- 提早降落可以減少傷害，但不能修好已經變弱的電芯。
- 不能只看容量標示判斷這顆電池還能放多大電流。

:::advanced 進階：靜置電壓、負載電壓與過放
飛行中推油門時的電壓（負載電壓）會比靜置電壓低很多，兩者不能直接比較。判斷是否過放，要依電芯規格區分負載下的壓降與靜置電壓，不能把所有電池低於某一個數字都當成同樣程度的損傷。
:::

:::checks 怎樣算修好
- 平衡充飽靜置約十分鐘後，每一節電壓的最大差距在約 0.05V 以內（一般 LiPo／LiHV 的參考值），而且同一顆電池前後幾次量的結果相近
- 連續幾次飛行後，沒有固定某一節特別低
- 充電時沒有局部發熱（用手背短暫輕碰或紅外線溫度計比較各處）
:::

:::stop 什麼時候停手
同一節反覆明顯落後（參考值約 0.1V 以上）、放著也一直掉電、充電時局部發熱，或電池鼓包：停止使用，不要取消平衡功能直接硬充。充電中發熱時，可以安全操作就先關掉充電器或拔掉充電電源；電池發熱、冒煙或有火花時不要用手拿、不要搬運，人先遠離觀察；有火勢就離開現場並打 119。
:::
