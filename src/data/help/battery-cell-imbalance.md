:::safety 開始前
電表切到直流電壓（V）檔，不要用電流檔。量單節時，兩支探棒各碰一根相鄰的針腳；同一支探棒的金屬尖端不要同時碰到兩根針腳，會造成短路。電池有鼓包、異味或發熱，直接停用。
:::

## 建議檢查順序

1. **平衡充飽後靜置約十分鐘**：再量每一節電壓。剛充完的電壓會稍微回落，靜置後才準。
2. **先排除平衡頭**：看針腳有沒有氧化、歪掉，插到底後再量一次。也可以用另一台充電器或可靠的電壓表比對。
3. **一次就差很多，先停用**：排除量測問題（重插平衡頭、換一台充電器或電表再量）之後，靜置後落差仍超過約 0.1V（本站保守的安全門檻，不是通用的故障標準），或有局部發熱、放著就掉電，不用再觀察幾次，直接停用。落差只在 0.05V 左右（本站保守門檻）時，才需要記錄幾次、看是不是固定同一節變低。
4. **小落差時才需要記錄**：落差只在約 0.05V（本站保守門檻）時，之後每次充飽靜置都量一次並記下來；也可以飛完落地後再量，看是不是同一節下降特別快。落差變大到約 0.1V，就照第 3 步停用。

## 看結果判斷

表中的 0.05V、0.1V 是本站為了安全刻意訂得**保守**的參考門檻，適用一般 LiPo／LiHV 在**充飽或存放電壓、靜置後**的量測，用來決定要不要多注意、要不要先停用。它**不是通用的電池故障標準**，也不是原廠或業界統一的數字：超過 0.1V 不代表電池一定壞了，只是本站建議先停用、交給有工具的人檢測（例如量內阻、容量）再決定；低於 0.05V 也不代表電池一定健康。電量很低或剛飛完還沒靜置時，各節落差會看起來比較大；Li-ion 在低電量區的電壓曲線比較陡，同樣的容量差會顯示成比較大的壓差；沒有平衡線的電池組沒辦法平衡充，落差也會慢慢累積。請以同一顆電池前後比較、以及原廠說明為準。

| 看到的狀況 | 代表什麼 | 下一步 |
| --- | --- | --- |
| 換一台充電器或重插後就正常 | 平衡頭接觸不良 | 清理或更換平衡頭 |
| 靜置後落差約 0.05V（保守門檻） | 可能開始不平衡，要注意 | 每次都用平衡充，照第 4 步記錄；落差變大到約 0.1V 就停用 |
| 排除量測問題後，靜置落差超過約 0.1V（保守門檻） | 那一節可能已經變弱（不等於確定故障） | 先停用這顆電池，不需要再飛幾次確認；要確認好壞，交給有內阻、容量測試工具的人檢測 |
| 平衡充一直卡在最後，某一節追不上 | 充電器平衡能力有限，或那一節異常 | 依充電器規格降低充電電流觀察，差距沒有縮小就停用 |
| 同一節放著也一直掉電、或充電時特別熱 | 電芯異常 | 立刻停用 |

## 為什麼總電壓正常，還是會有弱的那一節？

很多飛控和眼鏡顯示的「每節電壓」，其實是總電壓除以節數算出來的平均值，看不到最弱的那一節。所以飛行中畫面看起來還有電，最弱的那一節可能已經過低。

- 落地後量每一節並記錄，和同樣飛法的過去紀錄比較。
- 提早降落可以減少傷害，但不能修好已經變弱的電芯。
- 不能只看容量標示判斷這顆電池還能放多大電流。

:::advanced 進階：靜置電壓、負載電壓與過放
飛行中推油門時的電壓（負載電壓）會比靜置電壓低很多，兩者不能直接比較。判斷是否過放，要依電芯規格區分負載下的壓降與靜置電壓，不能把所有電池低於某一個數字都當成同樣程度的損傷。
:::

:::checks 怎樣算修好
- 平衡充飽靜置約十分鐘後，每一節電壓的最大差距在約 0.05V 以內（一般 LiPo／LiHV 的保守參考門檻），而且同一顆電池前後幾次量的結果相近
- 原本落差約 0.05V、需要觀察的電池：之後幾次充飽靜置量測，落差沒有變大
- 充電時沒有局部發熱（用手背短暫輕碰或紅外線溫度計比較各處）
:::

:::stop 什麼時候停手
排除量測問題後，靜置落差約 0.1V 以上（本站保守安全門檻，量到一次就算）、放著也一直掉電、充電時局部發熱，或電池鼓包：停止使用，不要取消平衡功能直接硬充。充電中發熱時，可以安全操作就先關掉充電器或拔掉充電電源；電池發熱、冒煙或有火花時不要用手拿、不要搬運，人先遠離觀察；有火勢就離開現場並打 119。
:::
