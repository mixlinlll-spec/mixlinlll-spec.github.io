:::safety 開始前
電池鼓包、破損、有異味或發熱，不要充電，直接看文末「什麼時候停手」與 [[battery-swelling]]。判斷溫度時，先看有沒有鼓脹、異味、冒煙；都沒有，才用手背短暫輕碰外皮判斷溫度，不要整顆握住或拿起來（有紅外線溫度計更好）。電池很冷（接近 0°C）或剛飛完還燙時也不要充，先回到室溫；Li-ion 以電芯規格書的充電溫度範圍為準。充電時人要在旁邊，放在不可燃的表面或防火袋裡。
:::

## 建議檢查順序

1. **看充電器顯示的每節電壓**：多數充電器接上平衡線後可以看到每一節的電壓。先記下來，後面判斷都用得到。
2. **看設定和電池是否一致**：電池種類（LiPo／LiHV／Li-ion）、節數（S）要和電池標籤相同，節數設錯時，充電器常會直接報錯。充電電流：標籤或原廠沒有寫充電倍率時用 1C（容量 mAh ÷ 1000，例如 1300mAh 設 1.3A）；有寫最大充電倍率才可以提高，不要超過。標籤上的「120C」這類數字是放電倍率，不是充電電流。
3. **看平衡頭**：白色小接頭的針腳有沒有氧化、歪掉、鬆脫，插到底了沒有。接觸不良時，充電器讀不到某一節，就會拒絕充電。
4. **交叉測試**：換一條充電線，再拿一顆正常的電池接同一台充電器。正常電池可以充，問題在原本那顆電池；正常電池也不能充，問題在充電器或線材。

## 看結果判斷

| 看到的狀況 | 代表什麼 | 下一步 |
| --- | --- | --- |
| 報「節數錯誤」 | 設定的節數和接上的不一樣，或平衡線有一節沒接觸到 | 改正節數，重新插好平衡頭 |
| 報「電壓過低」 | 有一節或整包電壓低於充電器允許開始充電的值 | 停止，不要切換其他模式硬充，看「什麼時候停手」 |
| 某一節顯示 0V 或數字亂跳 | 平衡頭接觸不良、平衡線斷，或那一節電芯已損壞 | 檢查平衡頭與線材；接觸正常仍是 0V，就停用這顆電池 |
| Li-ion 只充到約 4.1V 就結束 | 充電器的 Li-ion 模式終止電壓可能是 4.10V | 看充電器設定畫面的終止電壓，和電芯規格對照 |
| 換正常電池也不能充 | 充電器或充電線的問題 | 換線、看充電器說明書的錯誤代碼 |

## Li-ion 只能充到 4.1V，是充電器壞了嗎？

不一定。很多充電器的「Li-ion」模式終止電壓不同，名稱一樣不代表停在同一個電壓。

1. **查電芯規格**：電芯是 4.20V、4.10V 還是其他電壓上限。
2. **查充電器該模式的終止電壓**：看設定畫面或說明書上的數字，不要靠名稱猜。
3. **規格不明就不要調高**：絕對不要用 LiHV（4.35V）模式去「補」一般電芯的容量，這會過充。

## 能不能強制救電？

不建議。存放太久、被負載吃到過放的電池，充電器拒充是正常保護。

- 不要切換鎳氫或其他模式硬充，也不要接另一顆電池「喚醒」。
- 過放、鼓包、破皮、有異味或發熱的電池，交給專業處理。
- 以後存放時，拔掉飛機、蜂鳴器、電壓顯示器等會持續耗電的東西。

:::checks 怎樣算修好
- 充電器順利開始平衡充，沒有報錯
- 充電過程中每一節電壓一起上升，彼此差距很小
- 充完後每一節都停在標籤的滿電電壓，電池沒有明顯發熱
:::

:::stop 什麼時候停手
充電器報「電壓過低」：停止充電，不要切換其他模式硬充。電池鼓包、破損、有異味，或充電時明顯發熱：可以安全操作時先關掉充電器或拔掉充電電源，不要再嘗試充電。電池發熱、冒煙或有火花時不要用手拿、不要搬運，人先遠離觀察；有火勢就離開現場並打 119。
:::
