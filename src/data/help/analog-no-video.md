:::safety 開始前
圖傳沒接天線就不要通電，很容易燒壞。拆下螺旋槳，把飛機放在眼鏡前方 1～2 公尺處測試。
:::

## 先分出是哪一種畫面

| 眼鏡畫面 | 代表什麼 | 先查哪裡 |
| --- | --- | --- |
| A. 滿滿的雪花 | 眼鏡沒有收到這台圖傳的訊號 | 頻道、天線、圖傳有沒有供電 |
| B. 黑畫面，但看得到 OSD 文字（電壓、機名等） | 圖傳和飛控都在工作，只是鏡頭的影像沒有進到飛控 | 鏡頭的供電、鏡頭影像線、鏡頭本身 |
| C. 黑畫面，也沒有 OSD | 圖傳可能沒收到任何影像；也可能是眼鏡沒收到訊號時自動顯示黑幕 | 先排除眼鏡設定，再查飛控到圖傳的影像線 |

## 依畫面處理

:::case A 滿滿的雪花
1. **核對頻率數字**：眼鏡和圖傳都看「MHz 數字」，不要只看頻組字母，不同廠牌的字母代號不一定一樣。正常時兩邊數字相同。
2. **看圖傳有沒有亮燈**：接上電池後圖傳的指示燈沒亮，代表圖傳沒有供電，請看文末「還是不行？」。
3. **檢查兩端天線**：天線有沒有斷裂、鬆脫。SMA 與 RP-SMA 接頭外觀很像，插錯會讓訊號非常弱。
4. **拿近測試**：把飛機拿到眼鏡旁邊再自動搜台。只有很近才看得到，圖傳可能在低功率模式（Pit mode），到 Betaflight「圖傳」頁或用圖傳按鍵取消。
:::

:::case B 黑畫面，有 OSD
1. **斷電檢查鏡頭線**：鏡頭到飛控的 3 條線（供電、地線、影像）有沒有斷、焊點有沒有裂。摔機後最常在這裡掉線。
2. **看鏡頭的供電電壓**：對照鏡頭規格上的輸入電壓，和飛控供電焊點的電壓是不是同一個。
3. **換一顆正常的鏡頭**：換上就有畫面，代表原本的鏡頭壞了。
:::

:::case C 黑畫面，沒有 OSD
1. **先排除眼鏡的「黑幕」設定**：有些眼鏡或接收模組沒有訊號時會顯示黑畫面而不是雪花。把飛機斷電再看一次：畫面完全沒有變化，就當作狀況 A 處理。
2. **檢查飛控到圖傳的影像線**：斷電後看飛控「圖傳輸出」到圖傳「影像輸入」那一條線，有沒有斷或焊點裂開。
3. **（中階）繞過飛控測試**：斷電後把鏡頭影像線直接接到圖傳。有畫面但沒有 OSD，問題在飛控；仍然沒有畫面，問題在鏡頭或圖傳。需要焊接，不熟練的話請直接送修。
:::

本站不建議「通電狀態下用鑷子短接焊點」這類測試方法，碰錯一個點就可能燒壞飛控。

:::checks 怎樣算修好
- 眼鏡畫面清楚，OSD 文字疊在畫面上
- 拿著飛機走到平常起飛、降落的距離附近轉一圈，畫面不會一直中斷
- 依圖傳原廠的散熱說明短時間通電觀察：畫面不會越來越模糊或中斷。許多圖傳需要風扇或飛行時的氣流散熱，放在地上長時間通電會過熱，摸起來燙到不敢碰就先斷電
:::

:::stop 什麼時候停手
圖傳或鏡頭冒煙、有燒焦味，或插上電池時飛控的燈都不亮：立刻拔掉電池，不要再通電測試。
:::
