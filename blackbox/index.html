Tune Lab 飛行數據計畫

EWP Tune Lab 是電翼動力開發中的 Betaflight 調參分析系統。我們正在建立真實機型的飛行數據庫，用來校正濾波與 PID 的分析判斷。只要選飛機尺寸、傳一份黑盒子紀錄，約 5 分鐘；資料僅用於研發，不會公開。

01選飛機尺寸點一下就好 02匯出黑盒子SD 卡或內建 Flash 03用 LINE 傳送資料檔＋黑盒子檔

DIFF 和詳細規格是選填。在網站選檔案只是檢查，最後用 LINE 傳送才算完成。

02

匯出黑盒子

黑盒子記錄了飛行中的陀螺儀、電機和搖桿資料，還有整份 PID 與濾波設定。

先拆槳葉

接 USB 不需要插電池。如果一定要插電池，請先拆掉槳葉。

  1. 第一次錄：設定一次就好

    Configurator 連線 → 左側 黑盒子 → 記錄速率選 2 kHz（沒有就選最接近的）→ 儲存並重新啟動。

    看詳細設定
    BLACKBOX 建議設定BETAFLIGHT 4.3 以上
    記錄裝置 Logging device內建 Flash 或 SD 卡
    記錄速率 Logging rate2 kHz
    最低可接受1 kHz

    記錄速率太低會看不到高頻雜訊。用內建 Flash 的飛機，飛之前在同一頁按 清除 Flash（Erase flash）確保有空間；請先確認舊紀錄不需要了。

  2. 飛 1～3 分鐘

    照平常飛就好。有翻滾、急停、油門推到底更好。降落後先上鎖（Disarm）再拔電池。

  3. 把檔案拿出來

    SD 卡

    取出記憶卡接電腦，打開 LOGS 資料夾，複製最新的 LOG000xx.BFL。

    內建 Flash

    USB 接電腦 → Configurator 連線 → 黑盒子 頁 → 儲存 Flash 到檔案（Save flash to file），存成 .BBL。

    其他方法：隨身碟模式、手機 App
    • 隨身碟模式：黑盒子頁按 啟用 USB 隨身碟模式（Activate Mass Storage Device Mode），電腦會出現一顆隨身碟，把裡面的 .BBL 複製出來。
    • 手機：部分 SpeedyBee 飛控可用 SpeedyBee App 透過藍牙下載，但速度很慢。
    • 按鈕名稱會因 Configurator 版本與語言略有不同，位置大致一樣。
選擇黑盒子檔（.BBL／.BFL／.TXT） 只在你的瀏覽器裡檢查，選完還不算送出，最後要在步驟 03 用 LINE 傳送。確認可以用之後，再清除 Flash。

    隱私與常見問題
    
  
    
    
    
      
    
        為什麼只要尺寸和黑盒子？
        
    Betaflight 黑盒子檔的開頭會記錄整份 PID、濾波、Rate、韌體版本與飛控型號，電池串數也能從電壓算出來。黑盒子沒有的是飛機尺寸，而尺寸會影響共振頻率與合理的雜訊範圍，所以只請你選這一項。
    
      
    
      
    
        這個網頁會上傳我的檔案嗎？
        
    不會。檔案只在你的瀏覽器裡檢查。真正傳給我們的，只有你自己在 LINE 送出的檔案。填寫內容會暫存在這台裝置的瀏覽器，按「清除全部」就會刪除。
    
      
    
      
    
        資料會怎麼使用？
        
    只用在電翼動力調參工具的研發、校正與分析。不會公開你的 LINE 名稱或原始檔案；如果想把你的飛機當成公開案例，會先徵求你的同意。想刪除資料，在 LINE 告訴我們提交編號即可。
    
      
    
      
    
        飛機有 GPS，黑盒子會有位置嗎？
        
    有開 GPS 的飛機，黑盒子可能記錄飛行位置。檢查工具偵測到時會提醒你。介意的話可以只傳 DIFF，或在 LINE 先跟我們說。
    
      
    
      
    
        沒辦法匯出黑盒子，只有 DIFF 可以嗎？
        
    可以，在「選填」放入 DIFF 即可，但沒有黑盒子就看不到實際飛行狀況，分析會有限。
    
      
    
      
    
        不是 Betaflight（INAV、EmuFlight）可以嗎？
        
    目前以 Betaflight 4.3 以上為主。其他韌體也可以傳，但可能無法完整分析。
