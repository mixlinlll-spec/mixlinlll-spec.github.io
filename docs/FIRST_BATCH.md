## 每件公開前需要

1. 正式商品照片（1:1，至少 1 張，放 `assets/img/products/<id>/`，含 alt 文字）
2. `short_description`（1–2 句）與規格表（`specifications`）
3. 品牌、型號（`brand`、`manufacturer_model`）
4. 售價策略：定價／起價／詢價（不確定就維持詢價）
5. 供貨狀態（不確定就維持 `unknown`）
6. 蝦皮商品網址（`shopee_url`）或核實後的 shop ID
7. 確認後設定 `published: true`、`review.status: "approved"`

## 合規提醒

- 第 18–20 件整機含無線電發射模組（圖傳）。蝦皮曾因未填 BSMI／NCC 字號下架整機；官網公開販售前，請 EWP 先確認法規狀態與呈現方式（例如只作為作品展示、改為「客製組裝服務」詢價）。
- 第 15、16 件為射頻相關零件，公開前一併確認。
- 電池（第 4–6 件）的容量、放電規格請逐 SKU 核對，不以電芯型號推算。
