# 商品文案規範與人工確認清單（v2.10.0，2026-10-24）

## 一、文案規範（之後在 Pages CMS 修改商品時請照這份）

**標題**
- 繁體中文、台灣用語；品牌與型號放最前面，用「｜」分隔重點規格。
- 不堆疊關鍵字、不放 emoji、不放「【電翼動力】」等賣場前綴（EWP 自製商品品牌欄已是「電翼動力 EWP」）。
- 禁用：最強、絕對安全、永久防水、100%相容、保證、性能無虛標等無法證明的用語。

**說明**（只有「確實有內容」的段落才寫，不硬湊）
- 第一段直接寫商品是什麼、給誰用。
- 段落標題寫成單獨一行 `【產品特色】`，網站會顯示成小標題。
- 條列每行以 `・` 開頭，網站會顯示成清單。
- 建議順序：商品介紹／產品特色／規格／相容性／適用對象／包裝內容／注意事項。
- 規格放「規格表」，說明裡不要再重複一次。
- 不得補上來源沒有的規格、認證（BSMI、UN38.3、防水等級）或宣傳承諾。

**售後文字不寫在個別商品裡**
保固、七日鑑賞期、客製定義、蝦皮平台規範、到貨檢查，統一由 `src/data/notices.json` 產生，顯示在每個商品頁（含缺貨）最下方「購買與使用須知」。個別商品**不要**再寫：

- 保固三個月／一年／永久保固
- 拆封不退、訂製商品無法退貨
- 恕不負責、概不負責、不在保固範圍
- 一經焊接即視為接受等免責條款

**顏色選擇不是客製**：從既有顏色挑選，仍適用七日鑑賞期。真正依個人需求另外設計（改尺寸、孔位、雙色等）才屬客製，條件要在訂購前透過 LINE 說明。

**電池**：電芯放電數值一律寫「單顆電芯」，並和電池組的實際並聯數分開；峰值標示（如 MAX 180A）不得寫成持續輸出。

**射頻產品**（915MHz、高功率圖傳）：提醒使用前確認台灣法規與功率設定，不寫「台灣可合法使用」之類的判斷。

## 二、受保護欄位（文案修改時不可動）

`id`、`slug`、`shopee_item_id`、`shopee_url`、`sku`、`seller_role`、價格、供貨狀態、`published`、`review.status`、`variants`（key、蝦皮規格 ID、名稱、價格）、圖片 `src`／使用權。

檢查方式：`node scripts/check-protected-fields.mjs --base origin/main`（只在大量修改文案時手動執行；後台修改價格、上下架是正常操作，不列入自動測試）。
