:::safety 開始前
拆下螺旋槳。每次重新接線後第一次上電，都先接限流保護器（Smoke Stopper），它會在電流過大時限制或切斷電流，降低短路時直接燒板的機會。
:::

## 依狀況處理

:::case A USB 能連，但插上電池完全沒反應
1. **斷電目視檢查**：主電源插頭、電源線、飛控與電調之間的排線，有沒有鬆脫、破損或燒焦的痕跡。
2. **對照原廠接線圖**：排線型號與方向要和原廠圖一樣；插得進去不代表線序相同。
3. **用另一顆確定正常的電池試**：排除電池本身沒電或接頭損壞。
4. **曾經接反、有異味或發燙**：不要再上電，請看文末「還是不行？」。
:::

:::case B 限流保護器一接就跳
保護器跳掉或燈一直亮，可能是接錯線、零件短路，也可能只是設備開機瞬間的電流比較大（例如電容充電、數位圖傳開機）。燈只閃一下就熄通常是正常的；一直亮或跳掉，就要先停下來找原因。

1. **斷電檢查**：插頭方向、有沒有外露的金屬碰在一起、鬆脫的線材或燒焦痕跡；機身上的碳纖碎屑也會造成短路。
2. **看保護器的規格**：它要支援你使用的電池電壓。
3. **一次只接一個零件**：可以拔掉的周邊（圖傳、GPS）先拔掉再上電，找出是接上哪一個才會跳。
4. **看不出原因**：不要繞過保護器直接接電池，請看文末「還是不行？」。
:::

:::case C 接上圖傳飛控就重啟，拔掉圖傳就正常
1. **看電壓與電流**：飛控供電給圖傳的電壓（例如 5V、9V 或直接接電池電壓）要在圖傳規格的輸入範圍內，而且飛控那一路穩壓（BEC）的額定電流要大於圖傳的耗電；電流不夠時，圖傳一開機就會把電壓拉垮，讓飛控重啟。DJI O4 的供電範圍看 [[dji-o4-power-wiring]]。
2. **斷電檢查接線**：拔掉電池，對照圖傳與飛控的原廠接線圖，一條一條核對電源、GND、影像（或 TX／RX）線接在哪個焊點；插頭要插到底、方向和接線圖一樣；焊點要光亮、包住線頭，輕拉線材不會鬆動。
3. **交叉測試（有前提）**：先拔掉圖傳讓飛控單獨上電，飛控正常就繼續。要換接另一個確定正常的圖傳比較之前，先照 [[dji-o4-power-wiring]] 的「通電前怎麼量供電」量過預定接圖傳的焊點（圖傳先不要接；不會用電表就不要做這一步，看文末「還是不行？」）：電壓在圖傳規格範圍內、沒有冒煙發燙、限流保護器沒有跳；任何一項不符合就不要接上正常的圖傳，以免連它一起燒壞。條件都符合後，接上正常圖傳（第一次仍建議經過限流保護器）：換了就沒事，比較可能是原本的圖傳有問題。數位圖傳經過限流保護器時可能開不起來、燈一直亮，這不算「換了也一樣」；沒有冒煙發熱時，拿掉保護器直接接電池再比較。
4. **還是會重啟**：停止反覆上電，請看文末「還是不行？」。
:::

:::case D 兩套飛控／電調的排線插得進去，可以直接互換嗎？
不行直接換。接頭一樣，不代表每一根線的功能一樣，接錯可能一上電就燒板。

1. **找兩塊板子的原廠接線圖**。
2. **逐一對照每一根線**：電源、地線、電流感測、馬達訊號的位置要完全一樣，不要只看線的顏色。
3. **線序不同就換對的排線**：不要硬插或自己猜線序。
4. **第一次上電用限流保護器、拆槳**。
:::

:::checks 怎樣算修好
- 接限流保護器上電，保護器沒有跳，飛控與周邊的燈正常亮起（數位圖傳（DJI O4 等）開機電流大，透過限流保護器時可能開不起來，或保護器的燈一直亮；這不一定是短路。先拔掉圖傳確認其他部分正常，再拿掉保護器、直接接電池測圖傳）
- 接上全部零件、拆槳放在地上通電觀察一段時間（依設備散熱條件，不要讓沒有風吹的圖傳過熱），飛控不會自己重啟，沒有零件異常發燙
- 拿掉限流保護器、改接電池後，拆槳在「馬達」頁測試一切正常
:::

:::stop 什麼時候停手
冒煙、有燒焦味、任何零件幾秒內變燙，或曾經把電源接反：可以安全操作時立刻拔掉電池，不要再上電，也不要自行跨接電源或量測板上零件。電池本身發熱或冒煙時不要用手拿，人先遠離；有火勢就離開現場並打 119。
:::
