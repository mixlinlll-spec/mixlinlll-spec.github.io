:::safety 開始前
拆下全部螺旋槳。所有馬達測試都在拆槳狀態下進行，不要用手壓住或抓住裝了槳的飛機測試。
:::

## 依狀況處理

:::case A 解鎖後完全不轉
1. **先確認真的有解鎖**：拆槳撥解鎖開關後，看OSD 上的解鎖時間計時器（Betaflight 預設的計時器 2，只在解鎖時才會跳；計時器 1 預設是開機時間，一上電就在跳，不能拿來判斷）有沒有開始跳。沒有，代表飛控根本沒讓你解鎖，看 [[betaflight-arming]]。
2. **接上電池了嗎**：只插 USB 時，大多數電調不會供電給馬達，一定要接電池。
3. **聽開機聲**：接上電池時，電調會發出一段開機提示音。完全沒聲音，代表電調沒有供電，檢查電池接頭與電調電源線。
4. **看「馬達停止」設定**：打開 Motor Stop（馬達停止），而且沒有開 Airmode 時，解鎖後低油門不轉是正常的，推一點油門才會轉。開了 Airmode 時，Motor Stop 不會讓馬達停止。
5. **到「馬達」頁測試**：接上電池，勾選確認已拆槳，推動總控制滑桿。全部不轉，看文末「還是不行？」。
:::

:::case B 只有部分馬達會轉
1. **逐顆測試**：在「馬達」頁一次只推一顆的滑桿，記下哪一顆不轉。
2. **看那一顆的線**：馬達三條線有沒有斷、焊點有沒有裂、是否被機架夾到。
3. **用手轉一轉那顆馬達**：卡卡的、有沙沙聲，或有東西卡在裡面，先清理或更換馬達。
4. **還是不轉**：可能是電調那一路損壞，請看文末「還是不行？」。
:::

:::case C 會轉，但一起飛就翻或往一邊倒
1. **順序**：「馬達」頁推動 1 號滑桿時，轉的要是畫面圖上 1 號位置的那顆，依序測完 4 顆。位置不對時，順序要在設定裡改，不要直接交換電線了事：Betaflight App 的「馬達」頁有 Reorder motors（馬達重新排序）按鈕（依設定與混控類型才會出現），照畫面點選實際轉動的位置即可；看不到這個按鈕或不確定時，請看文末「還是不行？」。
2. **轉向**：每顆馬達的轉向要和「馬達」頁圖上的箭頭一樣。「馬達」頁上方 Mixer 區塊有 Motor direction is reversed（馬達反轉）開關：打開時，槳葉在機頭方向是向外轉（props out）；設定要和實際轉向一致。只有單顆轉反時，DShot 電調可以用同一區塊的 Motor direction 按鈕，照畫面把那一顆改過來；或交換那顆馬達三條線中的任兩條。不確定時請看文末「還是不行？」。
3. **槳的方向**：槳分正轉與反轉兩種，要和那顆馬達的轉向配對；槳上通常有標示（例如 R 或轉向箭頭），依槳的標示安裝。
4. **飛控方向**：「設定」頁的 3D 飛機，要和你手上飛機傾斜的方向一樣。方向相反，代表飛控安裝方向設定不對。

:::case D 拆槳解鎖後，馬達越轉越快
拆槳時飛控得不到機身姿態的回饋，會一直加大修正，所以馬達越轉越快。這在地面拆槳狀態下常見，不能單憑這個現象判定設定有問題。

1. **立刻上鎖**：不要讓馬達在桌上長時間空轉。
2. **改用「馬達」頁測試**：檢查順序與轉向時，用「馬達」頁逐顆低速測試，不要用解鎖代替。
3. **C 段都正常後**：裝槳到空曠處低空試飛，確認能穩定懸停。
:::

:::checks 怎樣算修好
- 「馬達」頁每顆的位置與轉向，都和畫面圖一致
- 拆槳解鎖：馬達以怠速轉動（開了 Motor Stop 時低油門不轉是正常的），上鎖後立刻停止；每顆轉速是否一致，在「馬達」頁用相同滑桿數值比較
- 裝槳後在空曠處低空起飛，能穩定懸停，不會往一邊翻
:::

:::stop 什麼時候停手
接上電池時馬達突然高速轉動、某顆馬達或電調很燙、冒煙或有燒焦味：可以安全操作時立刻拔掉電池，不要再試；電池本身發熱或冒煙時不要用手拿，人先遠離，有火勢就離開現場並打 119。
:::
