:::safety 開始前
拆下全部螺旋槳，所有地面測試都在拆槳狀態下進行。圖傳先接好天線再通電。
:::

## 建議檢查順序

1. **目視檢查**：焊點有沒有沾錫連在一起、線材有沒有被機架壓到、螺絲有沒有鎖緊、機身裡有沒有異物或碳纖碎屑。
2. **接限流保護器上電**：第一次接電池先經過限流保護器（Smoke Stopper），有短路時它會限制電流，降低燒板的機會。數位圖傳天空端第一次接之前，先照 [[dji-o4-power-wiring]] 的「通電前怎麼量供電」確認供電點電壓。
3. **連 Betaflight 檢查**：「設定」頁的 3D 飛機會跟著手轉（陀螺儀正常）、「接收機」頁撥搖桿時通道會動、電壓讀數和電池實際電壓接近。
4. **「馬達」頁逐顆測試**：前幾步都正常後，拿掉限流保護器、直接接電池再測（限流器會限制馬達需要的電流）。順序與轉向都和畫面圖一致，詳見 [[motors-after-arming]]。
5. **測試解鎖與失聯保護**：拆槳狀態下解鎖、上鎖都正常；失聯保護照 [[failsafe-check]] 的步驟，在解鎖狀態下關閉發射模組實測。
6. **裝槳低空試飛**：到空曠處低高度懸停，觀察有沒有異常震動或往一邊偏。

## 看結果判斷

| 看到的狀況 | 代表什麼 | 下一步 |
| --- | --- | --- |
| 接上電池時，限流保護器的燈一直亮著，或保護器跳掉 | 可能有短路或接線錯誤 | 拔電，回到第 1 步找焊點與接線問題，不要拿掉限流器硬接。燈只閃一下就熄，通常是電容充電的瞬間電流，不算異常；接了數位圖傳（DJI O4 等）時，先拔掉圖傳再試一次；不確定時照 [[power-wiring]] 的「限流保護器一接就跳」逐一排查 |
| 某個零件幾秒內變燙 | 該零件或它的供電有問題 | 立刻拔電，看 [[power-wiring]] |
| 3D 飛機不會動 | 陀螺儀沒有讀到 | 看 [[firmware-update]] 的「找不到陀螺儀」 |
| 撥搖桿通道不動 | 接收機沒有連上或設定不對 | 看 [[receiver-no-control]] |
| 馬達順序或轉向不對 | 設定或接線不對 | 看 [[motors-after-arming]] |

:::checks 怎樣算修好
- 接限流保護器上電，保護器沒有跳、燈沒有一直亮，沒有零件發燙（數位圖傳（DJI O4 等）開機電流大，透過限流保護器時可能開不起來，或保護器的燈一直亮；這不一定是短路。先拔掉圖傳確認其他部分正常，再拿掉保護器、直接接電池測圖傳）
- 「設定」頁 3D 飛機跟著手轉，「接收機」頁通道正常，「馬達」頁順序與轉向正確
- 飛控偵測得到失聯：App 連著、拆槳狀態下關掉遙控器，「設定」頁的 Arming Disable Flags 出現 RXLOSS（這只代表飛控知道沒收到訊號）；失聯保護實際會怎麼動作，照 [[failsafe-check]] 在解鎖狀態下實測
- 裝槳低空懸停穩定，沒有異常震動或偏移
:::

:::stop 什麼時候停手
上電時冒煙、有燒焦味，或任何零件幾秒內變燙：可以安全拔掉電池就立刻拔掉，之後不要再上電測試。限流保護器跳掉但沒有冒煙發燙：照 [[power-wiring]] 的「限流保護器一接就跳」排查，找到原因前不要拿掉保護器。電池本身發熱或冒煙時不要用手拿，先遠離並觀察，有火勢就離開現場並打 119。
:::
