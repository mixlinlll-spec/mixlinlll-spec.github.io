:::safety 開始前
拆下全部螺旋槳。這個問題沒排除前不要起飛：飛行中接收機重啟會直接失控。
:::

## 建議檢查順序

1. **比較兩種供電**：只接 USB 時看接收機燈號（有些飛控只插 USB 時，接收機那個焊點不會有電，燈不亮是正常的，查飛控說明書）；再接上電池，看燈號是否開始重新閃（代表接收機重啟了）。
2. **看接收機供電接在哪**：官方接線說明是接收機的 5V 接飛控的 5V（或 4.5V）焊點、地線接到地線焊點。焊點鬆動、地線接觸不良，插電池時容易重啟。
3. **拔掉圖傳測試**：斷電後先暫時拔掉圖傳再試。拔掉後不再重啟，比較可能是圖傳和接收機用的是同一組穩壓電路（BEC），圖傳開機時把電壓拉低。
4. **先查飛控的供電架構，再決定怎麼改**：飛控板上標「5V」的焊點通常有好幾個，但大多是同一組 5V 穩壓電路拉出來的，**把接收機換到另一個 5V 焊點通常沒有用**。看飛控說明書或原廠頁面的規格：
   - 板子有幾組獨立的穩壓電路（例如「5V 2A」「10V 2A」各一組），每個焊點屬於哪一組。
   - 每一組的額定電流，和接在那一組上的設備（接收機、圖傳、鏡頭、GPS、LED）加起來的耗電。
   - 圖傳規格允許的話，讓圖傳改接另一組獨立的穩壓（例如 9V／10V），接收機留在 5V；圖傳的輸入電壓一定要在它的規格範圍內，接法照 [[power-wiring]] 的量測方式先量過再接。
   - 說明書沒寫供電架構、或兩樣都只能接同一組時，不要自己改線，看文末「還是不行？」。
5. **仍然會重啟**：看文末「還是不行？」。不要自己把圖傳和接收機的供電並聯，也不要把接收機改接到電池電壓。

## 看結果判斷

| 看到的情況 | 代表什麼 | 下一步 |
| --- | --- | --- |
| 只接 USB 正常，接電池時燈號重新閃 | 電池供電時接收機重啟 | 斷電後用放大鏡看接收機 5V 與 GND 焊點有沒有裂開、虛焊（焊點應該光亮、包住線頭）；再拆槳、接電池，電表切到直流電壓（V）檔，黑棒碰飛控的 GND 焊點，紅棒碰該零件的電源焊點，讀數約 5V（有些飛控標 4.5V） |
| 拔掉圖傳後不再重啟 | 比較可能是圖傳和接收機共用的那組穩壓（BEC）被拉低或超載；也可能是圖傳排線、地線有問題 | 照第 4 步查飛控有幾組獨立穩壓與額定電流，再決定圖傳要不要改接另一組；換到同一組的另一個 5V 焊點通常沒有用 |
| 動一動線就重啟 | 焊點或線材接觸不良 | 斷電後重新焊接或更換線材 |
| 接電池後接收機或飛控發燙 | 可能有短路或供電錯誤 | 看下方「什麼時候停手」 |

:::checks 怎樣算修好
- 接上電池後，接收機燈號維持恆亮，不再重新閃
- 拆槳狀態下解鎖、推一點油門，接收機燈號仍然維持恆亮
- 插拔電池多次，每次都能正常連線
:::

:::stop 什麼時候停手
飛行中曾經掉線或重啟：立刻停飛。接上電池時接收機或飛控冒煙、有焦味：不要用手去碰發燙的零件；能安全拔掉電池就拔掉，然後遠離觀察，有起火就離開現場並打 119。
:::
