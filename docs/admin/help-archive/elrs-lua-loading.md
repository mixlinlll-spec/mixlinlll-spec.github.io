:::safety 開始前
修改遙控器模型設定前，先備份模型。這篇只動遙控器端，不用接飛機。
:::

## 建議檢查順序

1. **腳本放的位置**：`elrs.lua` 要放在遙控器記憶卡的 `SCRIPTS/TOOLS` 資料夾，從系統選單的「工具」打開。放在其他資料夾，選單裡會找不到或打不開。
2. **這個模型有沒有啟用發射模組**：目前選用的模型要設定使用 ELRS 發射模組（內建或外接）。模組沒有啟用時，腳本永遠停在載入中。
3. **模組的鮑率（Baud rate）**：內建或外接模組都要看。鮑率在 EdgeTX 的「模型設定」或系統選單的「硬體」頁（依遙控器而定）；官方說明從 3.3.0 起，外接模組封包率 333Hz 以上需要高於 400K 的鮑率。調高鮑率後要重新開機遙控器才會生效。
4. **腳本版本**：發射模組是 3.x 韌體就用 3.x 的腳本，2.x 用 2.x 的腳本，版本不對會一直載入。
5. **還是卡住**：先建一個新的模型設定檔測試，不要急著重刷整台遙控器。

## 看結果判斷

| 看到的情況 | 代表什麼 | 下一步 |
| --- | --- | --- |
| 「工具」選單裡找不到 ExpressLRS | 腳本沒放在 `SCRIPTS/TOOLS` | 把 `elrs.lua` 移到正確資料夾 |
| 換到另一個模型就打得開 | 原模型的發射模組設定不同 | 對照兩個模型的發射模組設定 |
| 調高鮑率並重新開機後打得開 | 原本的鮑率不夠 | 維持較高的鮑率 |
| 所有模型都打不開 | 「硬體」頁的鮑率不夠、模組沒供電或沒插好，或腳本與模組韌體版本不符 | 先調高鮑率並重新開機，再看模組燈號與版本 |

:::checks 怎樣算修好
- 打開 ExpressLRS 腳本，可以看到發射模組的設定選單（封包率、發射功率等）
- 關機再開機後，腳本仍然可以正常打開
- 換回原本要飛的模型，腳本一樣可以打開
:::

:::stop 什麼時候停手
外接模組插上後明顯發燙、有焦味：先把遙控器關機，不要再開機測試。不確定韌體型號時，不要自己重刷發射模組。
:::
