# 故障排除中心簡化改版：35 篇定位決定（2026-10-29）

**新標準**：一般 FPV 玩家遇到問題，能不能在幾分鐘內看懂、完成安全的初步檢查，或知道應該停止並求助。

- 每篇只保留：問題、常見原因 2～3 個、檢查步驟 3～5 步、怎樣算修好、什麼時候停手、還是不行（聯絡 EWP，版型自動產生）。
- 刪除：命令列指令、底層參數、Betaflight 各版本差異、原始碼說明、電路與穩壓分析、需要儀器或空中驗證的測試、分情況長篇（A／B／C 段）、進階段落、虛擬模式截圖。
- 原始 35 篇完整技術內容保留在 `docs/admin/help-archive/`（內部資料，不會發布）。
- 本次改版沒有實機驗證；字數為中文字數（不含英文、數字與標點）。

## 三、只列真正影響安全或會造成明顯錯誤操作的地方

| 文章 | 處理 |
| --- | --- |
| 新機第一次上電 | 保留：必須拆槳、經過限流器；冒煙／焦味／限流器跳掉就拔電、不要再插。數位圖傳過限流器可能開不起來的例外保留一句。 |
| 失聯保護 | 只教拆槳地面測試，明寫「不需要也不建議在空中測試」；設定成 GPS 返航或降落的飛機，結果不同，交給 EWP。GPS 救援整篇移出。 |

| 解鎖不了 | 解鎖測試先拆槳；解鎖後馬達自己加速就停手。 |
| 電池（5 篇） | 鼓包、異味、發燙、過低電壓不硬充；0.1V 標示為本站保守門檻，不是通用故障標準。 |
| 接收機一插電池就重啟 | 不再教改接 5V 焊點（涉及穩壓設計），改為停飛送修。 |
| 類比圖傳 | 沒接天線不要通電。 |
