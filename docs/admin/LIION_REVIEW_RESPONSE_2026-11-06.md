查核來源：ChatGPT〈PR #61 技術查核紀錄〉（2026-11-06，SHA 51aab3d）。以下逐項標示：採納／部分採納／不採納（理由）。沒有實機驗證；WebGL 未在實體手機測試。

| 項目 | 決定 | 處理 |
| --- | --- | --- |
| 01 充電模式 | 採納 | 改成看充電器畫面的每節截止電壓 4.20V；註明各家 Li-ion 模式不同（SkyRC B6 V2 說明書：LiIon 4.08–4.2V 可調）；絕不用 LiHV。 |
| 02 1.5C | 部分採納 | 1.5C／1C 是業主對自家產品的指定，保留並改為「照商品頁的建議值」；其他品牌依原廠。計算器預設改 1C，並註明只是換算、不代表可用電流。 |
| 03 標稱 3.6／3.7V | 採納 | 計算器加 3.6／3.7V 選項；文中電壓與瓦時改為範圍，以標籤為準。分級結果不受影響。 |
| 04 3.3V 降落 | 採納 | 改成「落地靜置下限」，明寫不是眼鏡警告值，空中要提早返航。 |
| 05 外場電包輸出 | 部分採納 | 加接頭極性、充電功率不要開太大、發燙就停、用電壓而不是電量格判斷。不寫最大瓦數（沒有正式額定）。 |
| 06 航空規定 | 採納 | 依 IATA 行動電源指引（ICAO 2026 修正）：行動電源超過 100Wh 不能帶上客機、每人 2 個；備用電池 100–160Wh 須航空公司同意、最多 2 顆。外場電包明寫不要帶上飛機。 |
| 07 動畫 | 採納 | 圖說加「示意動畫，不是組裝教學，請勿自行點焊」；動畫頁尾標「示意動畫」。 |
| 08 LiPo 也是鋰離子 | 採納 | 加一句說明。 |
| 09 不適合花飛 | 採納 | 改為「花飛、競速一般還是用 LiPo」。 |
| 10 鐵殼耐撞 | 採納 | 改為不易鼓包，但摔凹一樣要停用。 |
| 11 並聯倍數 | 採納 | 加「電芯配對良好時」「實際受焊接、接頭、線材限制」。 |
| 12 全部全極耳 | 不採納 | 業主已確認所有 6S 款都使用全極耳電芯；商品頁若寫法不同，屬商品頁待更新。 |
| 13 紫銅散熱 | 部分採納 | 保留導電與減少連接處發熱（電阻物理）；刪掉「不容易局部過熱」。 |
| 14 出廠配對 | 不採納 | 業主自述工藝（電壓、內阻檢查），商品頁已有相同說明。 |
