## 三、未執行的驗收門檻

- **低階 Android 實機效能**：無法在我的環境執行，需業主用實際手機開預覽站確認。
- **768px 畫面**：本輪只截了 390／320px 與電腦版首頁，未另截 768px。

## 四、仍待業主確認（商品頁，非本文）

1. `sp-53514957903`（LR 10000）寫「最大放電：180A」：業主說明 JP50 瞬間（5 秒內）180A，但未確認是單顆還是整包；6S2P 整包瞬間可能約 360A。這行未改。
2. `sp-46751039159`（靈雀 21700 6S2P）：瞬間 140A／持續 36A 是 18650 電芯的數字，和 21700 不符。
3. 「靈雀 長航鋰電池」與「電翼動力 高倍率長航鋰電池」是同一系列，重複上架兩頁。
4. 6S1P 5000mAh 目前官網沒有商品頁。
