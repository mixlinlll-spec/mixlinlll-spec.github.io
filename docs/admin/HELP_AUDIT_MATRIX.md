## analog-image-noise｜類比畫面隨油門出現橫紋、文字亂跳，或顏色變怪

- **本輪修改（3 處）**：

  1. 原句：4. **換穩定的供電比較**：斷電後改用乾淨的穩壓供電（例如圖傳的 5V 輸出、或飛控的穩壓焊點）給鏡頭，先確認那個輸出的電流夠用。EWP 實際案例中，改由圖傳 5V 輸出供電給鏡頭、影像經飛控 OSD 再進圖傳、全部共地後，橫紋消失；但不是每台都適用。
     改為：4. **換穩定的供電比較**：斷電後改用乾淨的穩壓供電（例如圖傳的 5V 輸出、或飛控的穩壓焊點）給鏡頭。先確認那個輸出的電壓在鏡頭規格的輸入範圍內（原本接 5V 的鏡頭改接 9V、10V 焊點可能燒毀），電流也夠用。EWP 實際案例中，改由圖傳 5V 輸出供電給鏡頭、影像經飛控 OSD 再進圖傳、全部共地後，橫紋消失；但不是每台都適用。
  2. 原句：4. **換電源畫面就差很多**：停止測試，檢查供電。 :::
     改為：4. **換電源畫面就差很多**：停止測試。拆槳、接電池，電表切到直流電壓（V）檔，黑棒碰飛控的 GND 焊點，紅棒碰鏡頭的電源焊點，讀數要在鏡頭規格的輸入範圍內；超出或不穩，回到 A 段第 4 步改用穩定的供電。 :::

- **本輪修改（1 處）**：

  1. 原句：4. **拿近測試**：把飛機拿到眼鏡旁邊再自動搜台。只有很近才看得到，圖傳可能在低功率模式（Pit mode），到 Betaflight「圖傳」頁或用圖傳按鍵取消。 :::
     改為：4. **拿近測試**：把飛機拿到眼鏡旁邊再自動搜台。只有很近才看得到，圖傳可能在低功率模式（Pit mode），或設定成上鎖時自動降功率（`vtx_low_power_disarm`）。到 Betaflight「圖傳」頁或用圖傳按鍵取消；「圖傳」頁無法操作時，看 [[analog-vtx-settings]]。 :::

- **依據**：cli/settings.c（vtx_low_power_disarm）；與 analog-vtx-settings 交叉
- **交叉核對的文章**：analog-vtx-settings
- **怎樣判斷修好**：- 眼鏡畫面清楚，OSD 文字疊在畫面上 ／ - 拿著飛機走到平常起飛、降落的距離附近轉一圈，畫面不會一直中斷 ／ - 依圖傳原廠的散熱說明短時間通電觀察：畫面不會越來越模糊或中斷。許多圖傳需要風扇或飛行時的氣流散熱，放在地上長時間通電會過熱，摸起來燙到不敢碰就先斷電

  1. 原句：:::safety 開始前 量測時不要讓電表探棒同時碰到平衡頭相鄰的兩根針腳，會造成短路。電池有鼓包、異味或發熱，直接停用。 :::

  2. 原句：表中的 0.05V、0.1V 是本站給一般 LiPo／LiHV 在**充飽或存放電壓、靜置後**量測的參考值，用來決定要不要多注意，不是所有電池種類、所有電量狀態下的故障標準。電量很低、剛飛完還沒靜置，或 Li-ion 電池組時，各節落差本來就會比較大；請以同一顆電池前後比較、以及原廠說明為準。
     改為：表中的 0.05V、0.1V 是本站給一般 LiPo／LiHV 在**充飽或存放電壓、靜置後**量測的參考值，用來決定要不要多注意，不是所有電池種類、所有電量狀態下的故障標準。電量很低或剛飛完還沒靜置時，各節落差會看起來比較大；Li-ion 在低電量區的電壓曲線比較陡，同樣的容量差會顯示成比較大的壓差；沒有平衡線的電池組沒辦法平衡充，落差也會慢慢累積。請以同一顆電池前後比較、以及原廠說明為準。
